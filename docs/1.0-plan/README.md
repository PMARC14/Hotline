## Agent connectors (Windows) — where to test
Hotline already discovers connectors through `odr.exe mcp list` (`OdrDiscovery`, shown as `windows-…` servers) when the file exists. This PC (26H2 build 26300.9711) has no `odr.exe` ("preview, not delivered"). The feature shipped as a public preview in Insider builds (Dev channel from build 26220.7262, and as native MCP in the 25H2 update KB5070316 per Windows Report): Settings > System > AI components > **Experimental agentic features** (administrator, off by default; a separate "reduce protections for more agent connectors" switch exists under Advanced settings > AI components). To test: a spare machine or a Hyper-V VM on a 25H2 build with that update or an Insider Dev build, toggle it on, run `odr mcp list`. Sources: <https://www.elevenforum.com/posts/674378/>, <https://windowsreport.com/kb5070316-adds-native-mcp-smarter-app-updates-and-midi-2-0-tools-to-windows-11-25h2/>, <https://www.theregister.com/2025/12/08/microsoft_windows_insiders_agentic_future/>, <https://geekrewind.com/?p=100348> (third-party, unverified against Microsoft Learn). If it cannot be tested before 1.0, ship the code as is, label it preview in the UI/docs, and move its verification to 1.1.
