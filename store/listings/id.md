## Deskripsi

Saya membuat ini karena tombol Copilot tidak melakukan hal yang berguna bagi saya. Hotline AI mengubahnya menjadi panel obrolan AI native yang berbicara dengan AI pilihan Anda.

Tekan tombol dan panel terbuka di monitor tempat Anda bekerja, siap untuk mengetik. Ajukan pertanyaan, dapatkan jawaban yang mengalir, tekan tombol lagi dan panel menghilang. Tanpa tab browser, tanpa akun di kami.

GUNAKAN AI YANG SUDAH ANDA MILIKI
• Claude Code: memakai Claude Code yang terpasang beserta akunnya, jadi paket Claude Anda bekerja tanpa kunci API.
• OpenAI Codex CLI: memakai Codex yang terpasang beserta akunnya, jadi paket ChatGPT Anda bekerja tanpa kunci API.
• Antigravity CLI (agy): Gemini dengan akun Google Anda.
• Kunci API Anda sendiri: Anthropic, Google Gemini, OpenAI, dan layanan kompatibel OpenAI lainnya seperti OpenRouter.
• Model lokal: server bergaya OpenAI apa pun di PC Anda (misalnya llama.cpp atau LM Studio), sehingga obrolan tetap di komputer Anda.
Pilih model, penyedia, dan seberapa keras ia berpikir langsung dari bilah panel.
Anda membawa layanan tersebut atau menjalankan modelnya sendiri. Hotline tidak menyertakan langganan AI.

BAWA KONTEKS ANDA
• Teks yang Anda pilih di aplikasi lain otomatis dilampirkan saat Anda menekan tombol, dan bisa Anda hapus sebelum mengirim.
• Tangkap jendela tempat Anda tadi, seluruh layar, atau area yang Anda seret; tempel atau letakkan gambar dan file.
• Model yang tidak bisa melihat gambar akan menerima teks dari tangkapan layar Anda, dibaca di PC Anda dengan OCR bawaan Windows.

DIBUAT UNTUK PEKERJAAN CEPAT
• Aksi cepat: ketik / untuk menerjemahkan, meringkas, memperbaiki, menjelaskan, membalas, memperpendek, formal, atau poin-poin, atau tulis aksi Anda sendiri sebagai file teks sederhana.
• Memori: "/remember saya lebih suka satuan metrik" dan setiap obrolan mengetahuinya, AI apa pun yang Anda pakai.
• Suara: atur tekan lama ke Input suara, tahan tombol dan berbicara; lepaskan untuk berhenti. Fitur ini menggunakan pengenalan suara daring Windows.
• Obrolan terbaru hanya sejauh satu klik, dalam daftar yang bisa dicari. Ctrl+H atau /resume juga membukanya. Obrolan CLI tetap berada di riwayat CLI itu sendiri dan dapat dilanjutkan setelah dimulai ulang.
• Click to Do dan aksi Windows: kirim teks atau gambar ke Hotline AI dari aplikasi lain.
• Continue in: bawa obrolan ke terminal, Open WebUI, UI web llama.cpp, LM Studio, atau target web atau aplikasi Anda sendiri. Open WebUI menerima obrolan sesungguhnya. LM Studio terbuka dengan obrolan yang sudah disalin untuk Anda tempel; target lain bervariasi.
• Saat panel memiliki fokus, gunakan pintasan untuk obrolan baru, obrolan terbaru, Pengaturan, sematkan, salin jawaban terakhir, tangkapan layar, prompt, serta pemilih model, penyedia, dan upaya penalaran. Tombol Anda sendiri juga bisa memilikinya. Pintasan memerlukan Ctrl, Alt, atau Win, sehingga tidak mengganggu pengetikan. Ubah di Pengaturan atau di toolbar.json.
• Dapatkan notifikasi Windows saat jawaban selesai ketika Anda berada di tempat lain.

NATIVE, RINGAN, DAN MILIK ANDA
• Dibuat dengan WinUI 3: cepat dibuka, mengikuti tema terang atau gelap Anda, tanpa browser tertanam. Native di x64 dan ARM64.
• Pilih warna aksen atau gunakan warna bawaan Windows. Tersedia tema Kontras tinggi, dan Hotline mengikuti tema kontras serta pengaturan transparansi Windows.
• Jawaban yang kaya: judul, daftar, tabel, kode dengan tombol Salin dan pengguliran ke samping, rumus matematika, dan gambar sederhana. Panel mengikuti jawaban saat muncul.
• Tahan Alt untuk memindahkan atau mengubah ukuran panel. Sematkan panel, pilih apakah obrolan bertambah ke atas atau ke bawah, dan atur suara buka/tutup. Lebar jendela menggunakan piksel nyata. Anda bisa memiliki panel pembuka yang sempit yang melebar saat obrolan dimulai.
• Semuanya berupa file biasa yang bisa Anda edit: pengaturan, koneksi, prompt, dan tombol di bilah.
• Baris tombol v2: seret tombol antar baris di Pengaturan > Jendela > Baris tombol, atau edit toolbar.json. Tambahkan tombol untuk aksi cepat atau teks siap pakai, dengan gambar PNG Anda sendiri. Pilih lebar dalam sel, atur ukuran setiap pemilih secara terpisah, dan tempatkan tombol yang jarang digunakan di menu Lainnya. Bilah yang sempit memindahkan tombol yang tidak muat ke dalam menu.
• Nilai pengaturan yang salah akan dialihkan kembali dengan peringatan; pengaturan lainnya tetap berlaku. Sebelum mengganti file pengaturan, koneksi, atau toolbar yang diedit manual, Hotline menyimpan cadangan. Jika pencadangan itu gagal, file tidak akan diubah. Hotline tidak membuat cadangan baru saat menimpa penyimpanan terakhirnya sendiri.
• Pengaturan > Cadangan mengekspor dan mengimpor pengaturan, baris tombol dan gambar, alat MCP, suara, koneksi, aksi cepat, dan prompt. Impor mencadangkan setiap file yang digantikannya terlebih dahulu; tanpa cadangan berarti tidak ada penulisan. Kunci API tidak pernah diekspor. Masukkan kembali di PC lain. Riwayat dan memori tidak disertakan dalam paket; nilai lingkungan MCP disertakan, jadi jaga kerahasiaan paket jika Anda menyimpan rahasia di sana.
• Alat, dengan hati-hati: koneksi API dapat memakai alat dari server MCP Anda; apa pun yang mengubah sesuatu akan bertanya dulu kecuali jika Anda telah mengizinkannya. Alat hanya-baca berjalan tanpa bertanya, berdasarkan apa yang dinyatakan oleh server.

PRIVASI SEJAK AWAL
Hotline AI tidak punya server dan tidak mengumpulkan apa pun: tanpa akun, tanpa analitik, tanpa iklan. Pesan Anda hanya dikirim ke layanan AI pilihan Anda, sesuai ketentuan layanan itu. Kunci API tetap di Manajer Kredensial Windows; riwayat, pengaturan, dan memori tetap di PC Anda. Gratis dan sumber terbuka.

Tidak punya tombol Copilot? Atur pintasan apa pun yang Anda suka, misalnya Ctrl+Alt+H, cukup dengan menekannya di Pengaturan.

Hotline AI adalah aplikasi independen dan tidak berafiliasi dengan atau didukung oleh Microsoft, Anthropic, Google, atau OpenAI. Menggunakan Claude Code, Codex, Antigravity CLI, atau API AI memerlukan akun Anda sendiri di layanan tersebut.
