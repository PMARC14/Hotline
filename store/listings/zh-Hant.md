## 描述

既然有 Copilot 鍵,不如好好運用。Hotline AI 把它變成快速的原生 AI 聊天面板,與你選擇的 AI 對話。

按下按鍵,面板就會在你正在使用的螢幕上開啟,可以直接輸入。提出問題,回答即時呈現;再按一次按鍵,面板隨即消失。不需要瀏覽器分頁,也不需要在我們這裡註冊帳戶。

使用你已有的 AI
• Claude Code:使用你已安裝的 Claude Code 及其登入,不需 API 金鑰即可使用你的 Claude 方案。
• OpenAI Codex CLI:使用你已安裝的 Codex 及其登入,不需 API 金鑰即可使用你的 ChatGPT 方案。
• Antigravity CLI (agy):使用你的 Google 帳戶存取 Gemini。
• 你自己的 API 金鑰:Anthropic、Google Gemini、OpenAI,以及 OpenRouter 等 OpenAI 相容服務。
• 本機模型:你電腦上任何 OpenAI 風格的伺服器 (例如 llama.cpp 或 LM Studio),資料不會離開你的電腦。
直接在面板的工具列中選擇模型、提供者和思考強度。

上下文隨你而來
• 你在其他應用程式中選取的文字,會在按下按鍵時自動附加,傳送前也可以移除。
• 擷取你先前所在的視窗、整個螢幕或拖曳選取的區域;可以貼上或拖入影像和檔案。
• 對於無法看到影像的模型,會改為傳送螢幕擷取畫面中的文字,這些文字由 Windows 內建的 OCR 在你的電腦上辨識。

專為快速工作打造
• 快速動作:輸入 / 即可翻譯、摘要、修正或解釋,也可以用簡單的文字檔撰寫自己的動作。
• 記憶:輸入「/remember 我偏好公制單位」,無論使用哪個 AI,每個聊天都會知道。
• 語音:按住按鍵說話,放開即停止。
• 最近的聊天一鍵可達。
• Click to Do 和 Windows 動作:從其他應用程式將文字或影像傳送到 Hotline AI。

原生、輕巧、由你掌控
• 以 WinUI 3 打造:啟動迅速,跟隨淺色或深色佈景主題,不內嵌瀏覽器。
• 豐富的回答:標題、清單、表格、附複製按鈕的程式碼、公式和簡單圖形。
• 一切都是可編輯的檔案:設定、連線、提示詞和工具列按鈕。
• 謹慎使用工具:API 連線可以使用你的 MCP 伺服器中的工具;任何會變更內容的動作都會先詢問你。

隱私至上
Hotline AI 沒有伺服器,也不收集任何資訊:沒有帳戶、沒有分析、沒有廣告。你的訊息只會依照服務條款傳送到你選擇的 AI 服務。API 金鑰保存在 Windows 認證管理員中;記錄、設定和記憶都保留在你的電腦上。免費且開放原始碼。

沒有 Copilot 鍵?可以設定任意快速鍵,例如 Ctrl+Alt+H。

Hotline AI 是一款獨立應用程式,與 Microsoft、Anthropic、Google 或 OpenAI 並無關聯,也未獲其背書。使用 Claude Code、Codex、Antigravity CLI 或 AI API 需要你在該服務中擁有自己的帳戶。

## 此版本的新功能

可選擇輔色 (Hotline 紫、Windows 輔色或任何色彩) 和新的高對比佈景主題;Hotline 也會跟隨 Windows 的對比佈景主題和透明效果設定。聊天歷程記錄會以可搜尋的清單開啟 (歷程記錄按鈕、Ctrl+↑ 或 /resume)。額外快速鍵只要按下即可設定。新的快速動作:/reply、/shorter、/formal 和 /bullets。程式碼區塊可橫向捲動,面板會跟著產生中的回答。

## 產品功能

1. 按 Copilot 鍵 (或任意快速鍵) 在你正在使用的螢幕上開啟,隨即可輸入
2. 使用你的 Claude Code、ChatGPT (Codex CLI) 或 Gemini (Antigravity CLI) 登入:不需 API 金鑰
3. 使用自己的金鑰:Anthropic、Google Gemini、OpenAI 及 OpenAI 相容 API
4. 本機模型:你電腦上任何 OpenAI 風格的伺服器,資料不離開電腦
5. 在面板中選擇模型、提供者和思考強度
6. 自動附加你在先前應用程式中選取的文字
7. 擷取視窗、螢幕或區域;貼上或拖入影像和檔案
8. 為無法看到影像的模型,在你的電腦上辨識螢幕擷取畫面文字 (OCR)
9. 快速動作:/translate、/summarize、/fix、/explain 或自訂動作
10. 無論使用哪個 AI,每個聊天都能看到的記憶
11. 按住按鍵即可語音輸入
12. 從 Click to Do 和其他應用程式傳送文字或影像
13. 豐富的回答:表格、可複製的程式碼、公式和圖形
14. 原生 WinUI 3,跟隨淺色或深色佈景主題
15. 一切皆為可編輯檔案:設定、連線、提示詞、工具列
16. 可選用 MCP 伺服器中的工具,任何變更前都需核准
17. 無帳戶、無分析、無廣告;金鑰保存在 Windows 認證管理員中
18. 免費且開放原始碼
19. 在 x64 和 ARM64 電腦上原生執行

2. 選取的文字會隨問題一起傳送。
3. 用 / 快速動作:翻譯、摘要、修正、解釋。
4. 使用你已有的 AI,一切依你的方式設定。
