## 描述

既然擺脫不掉 Copilot 鍵，不如物盡其用。Hotline AI 能將它變成一個快速的原生 AI 聊天面板，直接與你選擇的 AI 對話。

按下按鍵，面板就會在你正在使用的螢幕上開啟，隨時可以輸入。提出問題、取得即時串流回答，再按一次按鍵面板就會消失。沒有瀏覽器分頁，也不用註冊我們的帳號。

使用你已有的 AI
• Claude Code：使用你已安裝的 Claude Code 及其登入資訊，無需 API 金鑰即可使用你的 Claude 方案。
• OpenAI Codex CLI：使用你已安裝的 Codex 及其登入資訊，無需 API 金鑰即可使用你的 ChatGPT 方案。
• Antigravity CLI (agy)：使用你的 Google 登入來連線 Gemini。
• 你自己的 API 金鑰：Anthropic、Google Gemini、OpenAI 以及其他與 OpenAI 相容的服務，例如 OpenRouter。
• 本機模型：你電腦上的任何 OpenAI 樣式伺服器（例如 llama.cpp 或 LM Studio），任何資料都不會離開你的電腦。
直接從面板的按鈕列挑選模型、提供者，以及它該思考得多深入。

隨身攜帶脈絡
• 在其他應用程式中選取的文字會在按下按鍵時自動附加，你也可以在傳送前將其移除。
• 擷取你方才所在的視窗、整個螢幕或手動框選的區域；貼上或拖放圖片與檔案。
• 無法讀取圖片的模型會改為收到螢幕擷取畫面中的文字，由 Windows 內建的 OCR 直接在你的電腦上辨識讀取。

專為快速處理打造
• 快速動作：輸入 / 即可進行翻譯、摘要、修正或解釋，或是以簡單的文字檔編寫你自己的動作。
• 記憶：輸入「/remember 我偏好公制單位」，無論你使用哪種 AI，每次聊天都會記住這點。
• 語音：按住按鍵說話；放開即可停止。
• 最近的聊天只需按一下即可開啟，並收錄在可搜尋的清單中（Ctrl+H）。
• Click to Do 與 Windows 動作：從其他應用程式傳送文字或圖片至 Hotline AI。
• 繼續於：需要更多空間時，可將聊天帶到終端機、Open WebUI、llama.cpp 網頁介面、LM Studio 或你自己的目標中開啟。
• 當面板處於焦點時，為按鈕列的按鈕提供快速鍵：新聊天、最近的聊天、「設定」、釘選、擷取與選取器。你自己的按鈕也可以設定快速鍵。它們需要搭配 Ctrl、Alt 或 Win，因此絕不會影響一般輸入打字。
• 當你在其他地方忙碌時，Windows 通知會在回答完成時提醒你。

原生、輕巧且屬於你
• 以 WinUI 3 打造：開啟迅速、跟隨你的淺色或深色佈景主題，且沒有內嵌瀏覽器。在 x64 與 ARM64 上原生運作。
• 豐富的回答呈現：標題、清單、表格、附有「複製」按鈕的程式碼、數學公式與簡易繪圖。
• 按住 Alt 可移動面板或調整其大小；釘選面板，並選擇聊天畫面要向上或向下延伸。
• 一切都是你可以編輯的純文字檔案：設定、連線、提示詞，以及按鈕列中的按鈕。
• 依你的方式排列按鈕列：在「設定」中跨列拖曳按鈕、新增帶有自訂圖片的專屬按鈕，並將不常用的按鈕保留在「更多」選單中。
• 「設定」>「備份」可將你的設定轉移到另一部電腦。API 金鑰絕不會被匯出，而在 Hotline 替換檔案之前都會先備份。
• 謹慎使用工具：API 連線可以使用來自你 MCP 伺服器的工具；任何會造成變更的操作都會先詢問你。
• 如果你更希望如此，Copilot 鍵也可以直接當作右側 Ctrl 鍵使用。

從設計落實隱私
Hotline AI 沒有伺服器，也不會收集任何資料：沒有帳號、沒有分析追蹤、沒有廣告。你的訊息只會傳送至你選擇的 AI 服務，並遵守該服務的使用條款。API 金鑰妥善保存在 Windows Credential Locker 中；歷程記錄、設定與記憶則保留在你的電腦上。免費且開源。

沒有 Copilot 鍵？你可以設定任何喜歡的快速鍵，例如 Ctrl+Alt+H。

Hotline AI 是一款獨立應用程式，與 Microsoft、Anthropic、Google 或 OpenAI 無關，亦未獲得其背書。使用 Claude Code、Codex、Antigravity CLI 或 AI API 均需要你在該服務的專屬帳號。

## 此版本的新功能

在「設定」中排列按鈕列、新增自訂圖片的按鈕,並使用「更多」選單。以儲存格為單位設定按鈕寬度,並個別調整各選取器大小。工具列按鈕 (包括你自己的按鈕) 在面板處於焦點時皆可設定鍵盤快速鍵。「設定」>「備份」可在不包含 API 金鑰的情況下轉移你的設定;錯誤的設定值會發出警告,手動編輯的檔案在被替換前也會先備份。「繼續於」可在 Open WebUI、llama.cpp、LM Studio 或你自己的目標中開啟聊天 (部分需手動貼上)。視窗寬度使用真實像素,聊天畫面亦可變寬。我還修正了 Windows 11 26H2 上的 Copilot 鍵焦點處理、MCP 工具檢查、API 回應限制與備份失敗等問題。

## 產品功能

1. 按 Copilot 鍵 (或任意快速鍵) 在你正在使用的螢幕上開啟,隨即可輸入
2. 支援你的 Claude Code、ChatGPT (Codex CLI) 或 Gemini (Antigravity CLI) 登入:不需 API 金鑰
3. 使用自己的金鑰:Anthropic、Google Gemini、OpenAI 及 OpenAI 相容 API
4. 本機模型:你電腦上任何 OpenAI 風格的伺服器,聊天內容保留在電腦上
5. 在面板中選擇模型、提供者和思考強度
6. 自動附加你在先前應用程式中選取的文字
7. 擷取視窗、螢幕或區域;貼上或拖入影像和檔案
8. 為無法看到影像的模型,在你的電腦上辨識螢幕擷取畫面文字 (OCR)
9. 快速動作:/translate、/summarize、/fix、/explain 等,或你自己的文字檔
10. 無論使用哪個 AI,每個聊天都能看到的記憶
11. 使用 Windows 線上語音辨識的按住說話語音輸入
12. 從 Click to Do 和其他應用程式傳送文字或影像;在終端機、Open WebUI、llama.cpp 或 LM Studio 中繼續聊天
13. 豐富的回答:表格、附複製按鈕的程式碼、數學公式和圖形
14. 在 x64 和 ARM64 上原生執行的 WinUI 3;淺色、深色與對比佈景主題、自訂輔色,不內嵌瀏覽器
15. 在「設定」中拖放按鈕列;自訂按鈕搭配專屬圖片、「更多」選單與個別選取器寬度
16. API 連線的可選用 MCP 工具;除非已允許,任何變更都會先詢問
17. 無 Hotline 帳戶、分析或廣告;API 金鑰保存在 Windows 認證管理員中;免費且開放原始碼
18. 可編輯的設定、連線、提示詞與 toolbar.json;錯誤值會警告並回復,備份機制保護你的編輯
19. 「設定」>「備份」可匯出與匯入設定、工具列、MCP、音效、連線、快速動作與提示詞;絕不包含 API 金鑰
20. 工具列按鈕 (包含自訂按鈕) 的面板內快速鍵;可移動、釘選與調整面板大小,具像素寬度與加寬聊天選項
