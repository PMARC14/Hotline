## 描述

我做這個是因為 Copilot 鍵對我來說沒什麼用處。Hotline AI 把它變成原生的 AI 聊天面板,與你選擇的 AI 對話。

按下按鍵,面板就會在你正在使用的螢幕上開啟,隨即可輸入。提出問題,取得即時串流回答;再按一次按鍵,面板隨即消失。不需要瀏覽器分頁,也不需要在我們這裡註冊帳戶。

使用你已有的 AI
• Claude Code:使用你已安裝的 Claude Code 及其登入,不需 API 金鑰即可使用你的 Claude 方案。
• OpenAI Codex CLI:使用你已安裝的 Codex 及其登入,不需 API 金鑰即可使用你的 ChatGPT 方案。
• Antigravity CLI (agy):使用你的 Google 登入存取 Gemini。
• 你自己的 API 金鑰:Anthropic、Google Gemini、OpenAI,以及 OpenRouter 等其他 OpenAI 相容服務。
• 本機模型:你電腦上任何 OpenAI 風格的伺服器 (例如 llama.cpp 或 LM Studio),聊天內容保留在你的電腦上。
直接在面板的工具列中選擇模型、提供者和思考強度。
服務或模型需由你自己準備。Hotline 不包含 AI 訂閱方案。

上下文隨你而來
• 你在其他應用程式中選取的文字,會在按下按鍵時自動附加,傳送前也可以移除。
• 擷取你先前所在的視窗、整個螢幕或拖曳選取的區域;可以貼上或拖入影像和檔案。
• 對於無法看到影像的模型,會改為傳送螢幕擷取畫面中的文字,這些文字由 Windows 內建的 OCR 在你的電腦上辨識。

專為快速工作打造
• 快速動作:輸入 / 即可翻譯、摘要、修正、解釋、回覆、簡短、正式或列點,也可以用簡單的文字檔撰寫自己的動作。
• 記憶:輸入「/remember 我偏好公制單位」,無論使用哪個 AI,每個聊天都會知道。
• 語音:將長按設為語音輸入,按住按鍵說話,放開即停止。這使用 Windows 的線上語音辨識。
• 最近的聊天一鍵可達,以可搜尋的清單顯示。Ctrl+H 或 /resume 也能開啟。CLI 聊天會保留在 CLI 自己的歷程記錄中,重新啟動後也可以繼續。
• Click to Do 和 Windows 動作:從其他應用程式將文字或影像傳送到 Hotline AI。
• 繼續於 (Continue in):將聊天帶到終端機、Open WebUI、llama.cpp 網頁介面、LM Studio,或你自己的網頁或應用程式目標。Open WebUI 會接收完整的聊天。LM Studio 會開啟並已複製聊天內容供你貼上;其他目標則各有不同。
• 當面板處於焦點時,可以使用快速鍵進行新聊天、最近的聊天、設定、釘選、複製最新回答、擷取畫面、提示詞,以及模型、提供者和思考強度選取器。你自己的按鈕也可以設定快速鍵。它們需要配合 Ctrl、Alt 或 Win,因此絕不影響一般輸入。可以在「設定」或 toolbar.json 中變更。
• 當回答產生完成而你正在使用其他視窗時,接收 Windows 通知。

原生、輕巧、由你掌控
• 以 WinUI 3 打造:開啟迅速,跟隨淺色或深色佈景主題,不內嵌瀏覽器。在 x64 和 ARM64 上原生執行。
• 可選擇輔色或使用 Windows 內建色彩。提供高對比佈景主題,Hotline 也會跟隨 Windows 的對比佈景主題與透明效果設定。
• 豐富的回答:標題、清單、表格、附複製按鈕與橫向捲動的程式碼、數學公式和簡單圖形。面板會跟著串流中的回答捲動。
• 按住 Alt 即可移動或調整面板大小。可將其釘選、選擇聊天向上或向下展開,並設定開啟/關閉音效。視窗寬度使用真實像素。你可以讓面板以較窄的寬度開啟,在聊天開始後自動變寬。
• 一切都是可編輯的純文字檔:設定、連線、提示詞,以及工具列中的按鈕。
• 按鈕列第 2 版:在「設定」>「視窗」>「按鈕列」中跨列拖曳按鈕,或編輯 toolbar.json。可為快速動作或預設文字新增按鈕,並搭配你自己的 PNG 圖片。以儲存格為單位選擇寬度、個別調整每個選取器的大小,並將較少使用的按鈕放入「更多」選單中。較窄的工具列會將放不下的按鈕移入選單。
• 錯誤的設定值會發出警告並回復預設值;其他設定仍會套用。在替換手動編輯的設定、連線或工具列檔案前,Hotline 會先保留備份。若備份失敗,則不會變動該檔案。替換自身上次儲存的內容時不會重複建立備份。
•「設定」>「備份」可匯出與匯入設定、按鈕列與圖片、MCP 工具、音效、連線、快速動作與提示詞。匯入時會先備份每個被替換的檔案;無法備份就不會寫入。API 金鑰絕不匯出,需在另一部電腦上重新輸入。歷程記錄與記憶不包含在套件中;MCP 環境變數則包含在內,因此若其中含有機密資訊,請妥善保管套件私密性。
• 謹慎使用工具:API 連線可以使用你的 MCP 伺服器中的工具;任何會造成變更的動作都會先詢問你,除非你已預先允許。唯讀工具則會根據伺服器的宣告直接執行,無需詢問。

隱私至上
Hotline AI 沒有伺服器,也不收集任何資訊:沒有帳戶、沒有分析、沒有廣告。你的訊息只會依照該服務的條款傳送到你選擇的 AI 服務。API 金鑰保存在 Windows 認證管理員中;歷程記錄、設定和記憶都保留在你的電腦上。免費且開放原始碼。

沒有 Copilot 鍵?可以在「設定」中直接按下按鍵,設定任何你喜歡的快速鍵,例如 Ctrl+Alt+H。

Hotline AI 是一款獨立應用程式,與 Microsoft、Anthropic、Google 或 OpenAI 並無關聯,也未獲其背書。使用 Claude Code、Codex、Antigravity CLI 或 AI API 需要你在該服務中擁有自己的帳戶。

## 此版本的新功能

在「設定」中排列按鈕列、新增自訂圖片的按鈕,並使用「更多」選單。以儲存格為單位設定按鈕寬度,並個別調整各選取器大小。工具列按鈕 (包括你自己的按鈕) 在面板處於焦點時皆可設定鍵盤快速鍵。「設定」>「備份」可在不包含 API 金鑰的情況下轉移你的設定;錯誤的設定值會發出警告,手動編輯的檔案在被替換前也會先備份。「繼續於」可在 Open WebUI、llama.cpp、LM Studio 或你自己的目標中開啟聊天 (部分需手動貼上)。視窗寬度使用真實像素,聊天畫面亦可變寬。我還修正了 Windows 11 26H2 上的 Copilot 鍵焦點處理、MCP 工具檢查、API 回應限制與備份失敗等問題。
