## 简短说明

把 Copilot 键变成快速的 AI 聊天,使用你选择的 AI:你的 Claude 或 Gemini 登录、你自己的 API 密钥,或你电脑上的模型。按下按键、提问,回答即刻呈现。

## 说明

既然有 Copilot 键,不如好好用起来。Hotline AI 把它变成一个快速的原生 AI 聊天面板,与你选择的 AI 对话。

按下按键,面板就会在你正在使用的显示器上打开,可以直接输入。提出问题,回答实时呈现;再按一次按键,面板随即消失。不需要浏览器标签页,也不需要在我们这里注册账户。

使用你已有的 AI
• Claude Code:使用你已安装的 Claude Code 及其登录,无需 API 密钥即可使用你的 Claude 套餐。
• Antigravity CLI(agy):使用你的 Google 账户访问 Gemini。
• 你自己的 API 密钥:Anthropic、Google Gemini、OpenAI,以及 OpenRouter 等 OpenAI 兼容服务。
• 本地模型:你电脑上任何 OpenAI 风格的服务器(例如 llama.cpp 或 LM Studio),数据不会离开你的电脑。
在面板的工具栏中直接选择模型、提供方和思考强度。

上下文随你而来
• 你在其他应用中选中的文本会在按下按键时自动附加,发送前也可以移除。
• 截取你之前所在的窗口、整个屏幕或拖选的区域;可以粘贴或拖入图片和文件。
• 对于无法查看图片的模型,会改为发送截图中的文字,这些文字由 Windows 自带的 OCR 在你的电脑上识别。

专为快速任务打造
• 快速操作:输入 / 即可翻译、总结、修改或解释,也可以用简单的文本文件编写自己的操作。
• 记忆:输入“/remember 我更喜欢公制单位”,无论使用哪个 AI,每个聊天都会知道。
• 语音:按住按键说话,松开即停止。
• 最近的聊天一键可达。
• Click to Do 和 Windows 操作:从其他应用把文本或图片发送到 Hotline AI。

原生、轻快、由你掌控
• 基于 WinUI 3 构建:启动迅速,跟随浅色或深色主题,不内嵌浏览器。
• 丰富的回答:标题、列表、表格、带复制按钮的代码、公式和简单图形。
• 一切都是可编辑的文件:设置、连接、提示词和工具栏按钮。
• 谨慎使用工具:API 连接可以使用你的 MCP 服务器中的工具;任何会更改内容的操作都会先征求你的同意。
• 如果你愿意,Copilot 键也可以用作右 Ctrl 键。

隐私至上
Hotline AI 没有服务器,也不收集任何信息:没有账户、没有分析、没有广告。你的消息只会按照服务条款发送到你选择的 AI 服务。API 密钥保存在 Windows 凭据管理器中;历史记录、设置和记忆都保留在你的电脑上。免费且开源。

没有 Copilot 键?可以设置任意快捷键,例如 Ctrl+Alt+H。

Hotline AI 是一款独立应用,与 Microsoft、Anthropic、Google 或 OpenAI 没有关联,也未获得其认可。使用 Claude Code、Antigravity CLI 或 AI API 需要你在相应服务中拥有自己的账户。

## 产品功能

1. 按 Copilot 键(或任意快捷键)在你正在使用的显示器上打开,随即可输入
2. 使用你的 Claude Code 或 Gemini(Antigravity CLI)登录:无需 API 密钥
3. 使用自己的密钥:Anthropic、Google Gemini、OpenAI 及 OpenAI 兼容 API
4. 本地模型:你电脑上任何 OpenAI 风格的服务器,数据不离开电脑
5. 在面板中选择模型、提供方和思考强度
6. 自动附加你在之前应用中选中的文本
7. 截取窗口、屏幕或区域;粘贴或拖入图片和文件
8. 为无法查看图片的模型在你的电脑上识别截图文字(OCR)
9. 快速操作:/translate、/summarize、/fix、/explain 或自定义操作
10. 无论使用哪个 AI,每个聊天都能看到的记忆
11. 按住按键即可语音输入
12. 从 Click to Do 和其他应用发送文本或图片
13. 丰富的回答:表格、可复制的代码、公式和图形
14. 原生 WinUI 3,跟随浅色或深色主题
15. 一切皆为可编辑文件:设置、连接、提示词、工具栏
16. 可选使用 MCP 服务器中的工具,任何更改前都需批准
17. 无账户、无分析、无广告;密钥保存在 Windows 凭据管理器中
18. 免费且开源
19. Copilot 键也可改作右 Ctrl 使用
20. 在 x64 和 ARM64 电脑上原生运行
