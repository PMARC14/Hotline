## 简短说明

把 Copilot 键变成原生的 AI 聊天面板。使用你的 Claude、Codex 或 Gemini 登录、你自己的 API 密钥，或本地模型。调整工具栏布局、添加自定义按钮，并在需要更多空间时将聊天转移至其他应用。

## 说明

我做这个应用是因为 Copilot 键对我来说没什么用。Hotline AI 把它变成了一个原生的 AI 聊天面板，与你选择的 AI 对话。

按下按键，面板就会在你正在使用的显示器上打开，可以直接输入。提出问题，回答实时呈现；再按一次按键，面板随即消失。不需要浏览器标签页，也不需要在我们这里注册账户。

使用你已有的 AI
• Claude Code：使用你已安装的 Claude Code 及其登录，无需 API 密钥即可使用你的 Claude 套餐。
• OpenAI Codex CLI：使用你已安装的 Codex 及其登录，无需 API 密钥即可使用你的 ChatGPT 套餐。
• Antigravity CLI (agy)：使用你的 Google 登录访问 Gemini。
• 你自己的 API 密钥：Anthropic、Google Gemini、OpenAI 以及 OpenRouter 等 OpenAI 兼容服务。
• 本地模型：你电脑上任何 OpenAI 风格的服务器（例如 llama.cpp 或 LM Studio），聊天数据不会离开你的电脑。
在面板的工具栏中直接选择模型、提供方和思考强度。
你需要自行提供服务或运行模型。Hotline 不包含任何 AI 订阅。

上下文随你而来
• 你在其他应用中选中的文本会在按下按键时自动附加，发送前也可以移除。
• 截取你之前所在的窗口、整个屏幕或拖选的区域；可以粘贴或拖入图片和文件。
• 对于无法查看图片的模型，会改为发送截图中的文字，这些文字由 Windows 自带的 OCR 在你的电脑上识别。

专为快速任务打造
• 快速操作：输入 / 即可使用 /translate、/summarize、/fix、/explain、/reply、/shorter、/formal 或 /bullets，也可以用简单的文本文件编写自己的操作。
• 记忆：输入“/remember 我更喜欢公制单位”，无论使用哪个 AI，每个聊天都会知道。
• 语音：将长按设为语音输入，按住按键说话，松开即停止。此功能使用 Windows 的联机语音识别。
• 最近的聊天一键可达，以可搜索的列表呈现。也可以使用 Ctrl+H 或 /resume 打开。CLI 聊天会保存在 CLI 自身的历史记录中，重启后仍可恢复。
• Click to Do 和 Windows 操作：从其他应用把文本或图片发送到 Hotline AI。
• 转移到其他应用继续（Continue in）：将聊天转移至终端、Open WebUI、llama.cpp 网页界面、LM Studio，或你自定义的网页及应用目标。Open WebUI 会收到完整的真实聊天；LM Studio 会在打开时复制聊天内容供你粘贴；其他目标各不相同。
• 当面板处于焦点时，可使用快捷键来新建聊天、查看最近聊天、打开设置（Settings）、固定面板、复制最新回答、截屏、调用提示词，以及选择模型、提供方和思考强度。你自定义的按钮也可以设置快捷键。快捷键需要配合 Ctrl、Alt 或 Win，绝不会干扰正常输入。你可以在设置或 toolbar.json 中进行修改。
• 当你在其他应用中时，回答生成完毕会收到 Windows 通知。

原生、轻快、由你掌控
• 基于 WinUI 3 构建：启动迅速，跟随浅色或深色主题，不内嵌浏览器。在 x64 和 ARM64 电脑上原生运行。
• 可自选主题色或使用 Windows 自带的颜色。提供高对比度主题，Hotline 也会跟随 Windows 的对比度主题和透明效果设置。
• 丰富的回答：标题、列表、表格、带复制按钮和横向滚动的代码、公式和简单图形。面板会随着回答的实时生成自动滚动跟随。
• 按住 Alt 可移动面板或调整大小。固定面板、选择聊天向上还是向下延展，并可设置打开/关闭音效。窗口宽度使用真实像素；你可以设置打开时为窄面板，聊天开始后自动变宽。
• 一切都是可编辑的纯文本文件：设置、连接、提示词以及工具栏中的按钮。
• 按钮栏 v2：在“设置 > 窗口 > 按钮栏”（Settings > Window > Button rows）中跨行拖拽按钮，或直接编辑 toolbar.json。可为快速操作或预设文本添加按钮，并搭配你自己的 PNG 图片。按单元格选择宽度，单独调整每个选择器的大小，并将较少使用的按钮放入“更多”（More）菜单中。工具栏变窄时会自动将容纳不下的按钮移入菜单。
• 错误的设置项会发出警告并回退，其余设置依然生效。在替换手动编辑的设置、连接或工具栏文件前，Hotline 会先保留备份；若备份失败，则保持原文件不变。替换应用自身上次的保存时不会再次备份。
• “设置 > 备份”（Settings > Backup）导出和导入设置、按钮栏与图片、MCP 工具、音效、连接、快速操作及提示词。导入时会先备份所有将被替换的文件；若无法备份则不执行写入。API 密钥绝不会被导出，需在另一台电脑上重新输入。聊天历史和记忆不包含在备份包中；MCP 环境变量会包含在内，因此如果你在其中存放了机密信息，请妥善保管备份包。
• 谨慎使用工具：API 连接可以使用你 MCP 服务器中的工具；任何会更改内容的操作都会先征求你的同意，除非你已事先允许。只读工具会根据服务器声明直接运行，无需询问。

隐私至上
Hotline AI 没有服务器，也不收集任何信息：没有账户、没有分析、没有广告。你的消息只会按照服务条款发送到你选择的 AI 服务。API 密钥保存在 Windows 凭据管理器中；历史记录、设置和记忆都保留在你的电脑上。免费且开源。

没有 Copilot 键？可以在设置中直接按下按键设置你喜欢的任意快捷键，例如 Ctrl+Alt+H。

Hotline AI 是一款独立应用，与 Microsoft、Anthropic、Google 或 OpenAI 没有关联，也未获得其认可。使用 Claude Code、Codex、Antigravity CLI 或 AI API 需要你在相应服务中拥有自己的账户。

## 此版本的新增功能

在设置中排列按钮栏、添加带自定义图标的按钮，并使用“更多”菜单。按单元格设置按钮宽度，单独调整每个选择器的大小。面板处于焦点时，工具栏按钮（包括自定义按钮）均可使用键盘快捷键。“设置 > 备份”（Settings > Backup）可迁移配置且不包含 API 密钥；设置错误值会弹出警告，手动编辑的内容在被替换前会自动备份。“继续在...中打开”（Continue in）可在 Open WebUI、llama.cpp、LM Studio 或自定义目标中打开聊天（部分目标需手动粘贴）。窗口宽度使用真实像素，且聊天可自动变宽。我还修复了 Windows 11 26H2 上的 Copilot 键焦点处理、MCP 工具检查、API 响应限制以及备份失败的问题。
