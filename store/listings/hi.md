## संक्षिप्त विवरण

Copilot कुंजी से पीछा तो छूटना नहीं, तो इसका काम लें: आपके पास पहले से मौजूद AI (Claude, Codex, Gemini), अपनी API कुंजी या स्थानीय मॉडल के लिए तेज़, नेटिव AI चैट पैनल। हमारे यहाँ कोई खाता नहीं। बार व्यवस्थित करें और चैट को दूसरे ऐप में ले जाएँ।

## विवरण

Copilot कुंजी से पीछा तो छूटना नहीं, तो क्यों न इसका इस्तेमाल ही कर लिया जाए। Hotline AI इसे एक तेज़, नेटिव AI चैट पैनल में बदल देता है जो आपकी पसंद के AI से बात करता है।

कुंजी दबाएँ और आप जिस मॉनिटर पर काम कर रहे हैं, उस पर टाइप करने के लिए तैयार एक पैनल खुल जाता है। सवाल पूछें, स्ट्रीम होता जवाब पाएँ, कुंजी दोबारा दबाएँ और वह गायब। न कोई ब्राउज़र टैब, न हमारे यहाँ कोई खाता।

वही AI इस्तेमाल करें जो आपके पास पहले से है
• Claude Code: आपके इंस्टॉल किए गए Claude Code और उसके साइन-इन का उपयोग करता है, ताकि आपका Claude प्लान बिना किसी API कुंजी के काम करे।
• OpenAI Codex CLI: आपके इंस्टॉल किए गए Codex और उसके साइन-इन का उपयोग करता है, ताकि आपका ChatGPT प्लान बिना किसी API कुंजी के काम करे।
• Antigravity CLI (agy): आपके Google साइन-इन के साथ Gemini।
• आपकी अपनी API कुंजी: Anthropic, Google Gemini, OpenAI और OpenRouter जैसी अन्य OpenAI-संगत सेवाएँ।
• स्थानीय मॉडल: आपके PC पर कोई भी OpenAI-स्टाइल सर्वर (उदाहरण के लिए llama.cpp या LM Studio), जिससे आपके कंप्यूटर से कुछ भी बाहर नहीं जाता।
मॉडल, प्रोवाइडर और उसे कितना गहराई से सोचना चाहिए, यह सीधे पैनल के बार से चुनें।

संदर्भ अपने साथ लाएँ
• किसी दूसरे ऐप में आपके द्वारा चुना गया टेक्स्ट कुंजी दबाते ही अपने आप जुड़ जाता है, और आप भेजने से पहले उसे हटा सकते हैं।
• आप जिस विंडो में थे उसे कैप्चर करें, पूरी स्क्रीन या खींचकर चुना गया कोई हिस्सा कैप्चर करें; चित्र और फ़ाइलें पेस्ट करें या ड्रॉप करें।
• जो मॉडल छवियाँ नहीं देख सकते, उन्हें स्क्रीनशॉट की जगह उसमें मौजूद टेक्स्ट मिलता है, जिसे आपके PC पर Windows के अपने OCR द्वारा पढ़ा जाता है।

त्वरित कार्यों के लिए निर्मित
• त्वरित क्रियाएँ: अनुवाद, सारांश, सुधार या व्याख्या के लिए / टाइप करें, या साधारण टेक्स्ट फ़ाइलों के रूप में अपनी क्रियाएँ लिखें।
• मेमोरी: "/remember मुझे मीट्रिक इकाइयाँ पसंद हैं" और हर चैट को यह याद रहता है, चाहे आप कोई भी AI इस्तेमाल करें।
• आवाज़: कुंजी दबाए रखें और बोलें; रोकने के लिए छोड़ दें।
• हाल की चैट बस एक क्लिक दूर हैं, एक खोजने योग्य सूची में (Ctrl+H)।
• Click to Do और Windows क्रियाएँ: अन्य ऐप्स से Hotline AI को टेक्स्ट या चित्र भेजें।
• Continue in: जब आपको अधिक जगह चाहिए हो, तो चैट को किसी टर्मिनल, Open WebUI, llama.cpp वेब UI, LM Studio या अपने किसी टारगेट में ले जाएँ।
• पैनल फ़ोकस में होने पर बार के बटनों के शॉर्टकट: नई चैट, हाल की चैट, Settings, पिन, कैप्चर और पिकर। आपके अपने बटनों का भी शॉर्टकट हो सकता है। इनमें Ctrl, Alt या Win की आवश्यकता होती है, ताकि टाइपिंग पर कभी असर न पड़े।
• जब आप कहीं और हों और कोई उत्तर पूरा हो जाए, तो एक Windows सूचना आपको बता देती है।

नेटिव, हल्का और आपका अपना
• WinUI 3 से निर्मित: तेज़ी से खुलता है, आपके लाइट या डार्क थीम का अनुसरण करता है, कोई एम्बेडेड ब्राउज़र नहीं। x64 और ARM64 पर नेटिव।
• समृद्ध उत्तर: शीर्षक, सूचियाँ, तालिकाएँ, Copy बटन के साथ कोड, गणित और सरल रेखाचित्र।
• पैनल को स्थानांतरित करने या उसका आकार बदलने के लिए Alt दबाए रखें; इसे पिन करें, और चुनें कि चैट ऊपर की ओर बढ़े या नीचे की ओर।
• सब कुछ एक सामान्य फ़ाइल है जिसे आप संपादित कर सकते हैं: सेटिंग्स, कनेक्शन, प्रॉम्प्ट, बार के बटन।
• बार को अपने तरीके से व्यवस्थित करें: Settings में पंक्तियों के बीच बटन खींचें, अपने चित्रों के साथ अपने बटन जोड़ें, और कम उपयोग किए जाने वाले बटनों को More मेनू में रखें।
• Settings > Backup आपके सेटअप को दूसरे PC पर स्थानांतरित करता है। API कुंजियाँ कभी निर्यात नहीं की जातीं, और Hotline जिस फ़ाइल को बदलती है उसका बैकअप पहले लिया जाता है।
• टूल्स, सावधानी से: API कनेक्शन आपके MCP सर्वरों से टूल्स का उपयोग कर सकते हैं; कुछ भी बदलने वाली क्रिया पहले आपसे पूछती है।
• Copilot कुंजी Right Ctrl कुंजी के रूप में भी काम कर सकती है, यदि आप वैसा चाहें।

डिज़ाइन से ही निजी
Hotline AI का कोई सर्वर नहीं है और यह कुछ भी एकत्र नहीं करता: कोई खाता नहीं, कोई एनालिटिक्स नहीं, कोई विज्ञापन नहीं। आपके संदेश केवल आपकी चुनी हुई AI सेवा के पास जाते हैं, उस सेवा की शर्तों के तहत। API कुंजियाँ Windows Credential Locker में रहती हैं; इतिहास, सेटिंग्स और मेमोरी आपके PC पर रहती हैं। मुफ़्त और ओपन सोर्स।

Copilot कुंजी नहीं है? अपनी पसंद का कोई भी शॉर्टकट सेट करें, उदाहरण के लिए Ctrl+Alt+H।

Hotline AI एक स्वतंत्र ऐप है और यह Microsoft, Anthropic, Google या OpenAI से संबद्ध या उनके द्वारा समर्थित नहीं है। Claude Code, Codex, Antigravity CLI या किसी AI API का उपयोग करने के लिए उस सेवा पर आपका अपना खाता होना आवश्यक है।

## इस संस्करण में नया क्या है

Settings में बटन पंक्तियों को व्यवस्थित करें, अपने चित्रों के साथ बटन जोड़ें, और More मेनू का उपयोग करें। सेल में बटन की चौड़ाई सेट करें और प्रत्येक पिकर का आकार अलग से तय करें। पैनल फ़ोकस में होने पर बार के बटनों (आपके अपने बटन सहित) के कीबोर्ड शॉर्टकट हो सकते हैं। Settings > Backup बिना API कुंजियों के आपका सेटअप स्थानांतरित करता है; गलत सेटिंग मान चेतावनी देते हैं, और फ़ाइल बदलने से पहले आपके संपादनों का बैकअप लिया जाता है। Continue in चैट को Open WebUI, llama.cpp, LM Studio या आपके अपने टारगेट में खोलता है, कभी-कभी पेस्ट करने की ज़रूरत के साथ। विंडो की चौड़ाई वास्तविक पिक्सल का उपयोग करती है, और चैट और अधिक चौड़ी हो सकती है। मैंने Windows 11 26H2 पर Copilot कुंजी फ़ोकस, MCP टूल जाँच, API प्रतिक्रिया सीमा और बैकअप विफलताओं को भी ठीक किया है।

## उत्पाद सुविधाएँ

1. Copilot कुंजी (या किसी भी शॉर्टकट) से उसी मॉनिटर पर खुलता है जिस पर आप काम कर रहे हैं, टाइप करने के लिए तैयार
2. आपके Claude Code, ChatGPT (Codex CLI) या Gemini (Antigravity CLI) साइन-इन से चलता है: API कुंजी की ज़रूरत नहीं
3. अपनी कुंजी लाएँ: Anthropic, Google Gemini, OpenAI और OpenAI-संगत API
4. स्थानीय मॉडल: आपके PC पर कोई भी OpenAI-शैली सर्वर, ताकि चैट आपके कंप्यूटर पर ही रहे
5. पैनल से सीधे मॉडल, प्रदाता और सोचने का प्रयास चुनें
6. जिस ऐप से आप आए उसका चयनित टेक्स्ट अपने-आप संलग्न हो जाता है
7. विंडो, पूरी स्क्रीन या क्षेत्र कैप्चर करें; चित्र और फ़ाइलें चिपकाएँ या छोड़ें
8. चित्र न देख सकने वाले मॉडल के लिए स्क्रीनशॉट का टेक्स्ट आपके PC पर पढ़ा जाता है (OCR)
9. त्वरित क्रियाएँ: /translate, /summarize, /fix, /explain और अन्य, या अपनी साधारण टेक्स्ट फ़ाइलें
10. ऐसी मेमोरी जिसे हर चैट देखती है, AI चाहे कोई भी हो
11. Windows की ऑनलाइन वाक् पहचान का उपयोग करने वाला पुश-टू-टॉक वॉइस इनपुट
12. Click to Do और अन्य ऐप से टेक्स्ट या चित्र भेजें; चैट को टर्मिनल, Open WebUI, llama.cpp या LM Studio में जारी रखें
13. समृद्ध उत्तर: तालिकाएँ, Copy बटन वाला कोड, गणित और रेखाचित्र
14. x64 और ARM64 पर नेटिव WinUI 3; हल्की, गहरी और कॉन्ट्रास्ट थीम, आपका एक्सेंट रंग, कोई एम्बेडेड ब्राउज़र नहीं
15. Settings में बटन पंक्तियाँ खींचें; अपने चित्रों वाले कस्टम बटन, More मेनू और अलग-अलग पिकर चौड़ाई
16. API कनेक्शन के लिए वैकल्पिक MCP टूल; जब तक अनुमति न हो, बदलाव करने से पहले हमेशा पूछा जाता है
17. न खाता, न एनालिटिक्स, न विज्ञापन; API कुंजियाँ Windows Credential Locker में रहती हैं; निःशुल्क और ओपन सोर्स
18. संपादन-योग्य सेटिंग्स, कनेक्शन, प्रॉम्प्ट और toolbar.json; गलत मान पर चेतावनी, बैकअप आपके संपादन सुरक्षित रखता है
19. Settings > Backup सेटिंग्स, बार, MCP, ध्वनियाँ, कनेक्शन, त्वरित क्रियाएँ और प्रॉम्प्ट आयात/निर्यात करता है; API कुंजियाँ कभी नहीं
20. बार के बटनों (अपने बटनों सहित) के लिए इन-पैनल शॉर्टकट; पैनल मूव, पिन और रीसाइज़ करें, पिक्सल चौड़ाई व चौड़ी चैट का विकल्प

## स्क्रीनशॉट कैप्शन

1. Copilot कुंजी दबाएँ: कुछ भी पूछें, उत्तर तुरंत आता दिखेगा।
2. चयनित टेक्स्ट आपके सवाल के साथ जाता है।
3. / के साथ त्वरित क्रियाएँ: अनुवाद, सारांश, सुधार, व्याख्या।
4. वही AI इस्तेमाल करें जो आपके पास पहले से है, और सब कुछ अपने हिसाब से सेट करें।
