## Короткий опис

Нікуди подітися від клавіші Copilot — скористайтеся нею: швидка нативна панель для ШІ, який уже маєте (Claude, Codex, Gemini), власного ключа API чи локальної моделі. Без акаунтів у нас. Упорядковуйте панель і переносьте чат в іншу програму.

## Опис

Вам ніде подітися від клавіші Copilot, тож чому б не скористатися нею. Hotline AI перетворює її на швидку нативну панель чату з ШІ, яка спілкується з вибраним вами ШІ.

Натисніть клавішу — і панель відкриється на моніторі, де ви працюєте, одразу готова до введення. Задайте питання, отримайте потокову відповідь, натисніть клавішу ще раз — і вона зникне. Жодної вкладки браузера, жодного акаунта в нас.

КОРИСТУЙТЕСЯ ШІ, ЯКИЙ УЖЕ МАЄТЕ
• Claude Code: використовує встановлений Claude Code та ваш вхід у нього, тож ваш план Claude працює без ключа API.
• OpenAI Codex CLI: використовує встановлений Codex та ваш вхід у нього, тож ваш план ChatGPT працює без ключа API.
• Antigravity CLI (agy): Gemini з вашим входом у Google.
• Власний ключ API: Anthropic, Google Gemini, OpenAI та інші OpenAI-сумісні сервіси, як-от OpenRouter.
• Локальні моделі: будь-який сервер у стилі OpenAI на вашому ПК (наприклад, llama.cpp або LM Studio), тож нічого не залишає комп'ютер.
Вибирайте модель, постачальника та те, наскільки ретельно вона має думати, просто з панелі.

БЕРІТЬ КОНТЕКСТ ІЗ СОБОЮ
• Текст, виділений в іншій програмі, прикріплюється автоматично після натискання клавіші, і його можна прибрати перед надсиланням.
• Робіть знімок вікна, у якому ви були, усього екрана чи виділеної ділянки; вставляйте або перетягуйте зображення й файли.
• Моделі, які не бачать зображень, натомість отримують текст зі знімка екрана, прочитаний на вашому ПК за допомогою вбудованого OCR у Windows.

СТВОРЕНО ДЛЯ ШВИДКИХ ЗАВДАНЬ
• Швидкі дії: введіть / для перекладу, підсумовування, виправлення чи пояснення або створюйте власні у вигляді простих текстових файлів.
• Пам'ять: "/remember я віддаю перевагу метричним одиницям", і кожен чат це знає, хоч би який ШІ ви використовували.
• Голос: утримуйте клавішу та говоріть; відпустіть, щоб зупинити.
• Недавні чати відкриваються в один клік у списку з пошуком (Ctrl+H).
• Click to Do та дії Windows: надсилайте текст або зображення в Hotline AI з інших програм.
• Продовжити в: переносьте чат у термінал, Open WebUI, веб-інтерфейс llama.cpp, LM Studio чи власні програми, коли потрібно більше місця.
• Сполучення клавіш для кнопок панелі, поки панель у фокусі: новий чат, недавні чати, «Настройки», закріплення, знімки та селектори. Власні кнопки також можуть мати свої сполучення. Вони потребують Ctrl, Alt або Win, тому введення тексту ніколи не блокується.
• Сповіщення Windows повідомить, коли відповідь завершиться, поки ви займаєтеся іншими справами.

НАТИВНИЙ, ЛЕГКИЙ І ВАШ
• Створено на WinUI 3: відкривається миттєво, адаптується до світлої чи темної теми, без вбудованого браузера. Нативний для x64 та ARM64.
• Оформлені відповіді: заголовки, списки, таблиці, код із кнопкою копіювання, формули та прості малюнки.
• Утримуйте Alt, щоб перемістити панель або змінити її розмір; закріплюйте її та вибирайте, куди росте чат — угору чи вниз.
• Усе є простим файлом, який можна редагувати: налаштування, підключення, підказки, кнопки на панелі.
• Упорядковуйте панель на свій смак: перетягуйте кнопки між рядками в «Настройках», додавайте власні кнопки з власними зображеннями й залишайте менш уживані в меню «Більше».
• «Настройки» > «Резервна копія» переносить ваші налаштування на інший ПК. Ключі API ніколи не експортуються, а файл, який Hotline замінює, спершу резервується.
• Обережна робота з інструментами: підключення через API можуть використовувати інструменти з ваших серверів MCP; будь-яка дія, що вносить зміни, спершу запитує ваш дозвіл.
• Клавіша Copilot може також працювати як правий Ctrl, якщо вам так зручніше.

ПРИВАТНІСТЬ ЗА ЗАДУМОМ
Hotline AI не має серверів і нічого не збирає: жодних акаунтів, аналітики чи реклами. Ваші повідомлення надходять лише до вибраного вами сервісу ШІ згідно з його умовами використання. Ключі API зберігаються у Windows Credential Locker; історія, налаштування та пам'ять залишаються на вашому ПК. Безкоштовна програма з відкритим кодом.

Немає клавіші Copilot? Установіть будь-яке зручне сполучення клавіш, наприклад Ctrl+Alt+H.

Hotline AI є незалежною програмою і не пов'язана з Microsoft, Anthropic, Google чи OpenAI та не схвалена ними. Використання Claude Code, Codex, Antigravity CLI або API сервісів ШІ потребує власного облікового запису у відповідному сервісі.

## Що нового в цій версії

Впорядковуйте рядки кнопок у настройках, додавайте кнопки з власними зображеннями та використовуйте меню «Більше». Задавайте ширину кнопок у клітинках і розмір кожного селектора окремо. Кнопки панелі, включно з власними, можуть мати сполучення клавіш, поки панель у фокусі. «Настройки» > «Резервна копія» переносить ваші налаштування без ключів API; у разі помилкових значень виводиться попередження, а ваші редагування резервуються перед заміною. «Продовжити в» відкриває чат в Open WebUI, llama.cpp, LM Studio або ваших власних цілях (подекуди потрібно вставити текст). Ширина вікна використовує реальні пікселі, а чат може розширюватися. Я також виправив роботу фокуса клавіші Copilot у Windows 11 26H2, перевірки інструментів MCP, ліміти відповідей API та помилки резервного копіювання.

## Функції продукту

1. Відкривається клавішею Copilot (або будь-якою комбінацією) на моніторі, де ви працюєте, готовий до введення
2. Працює з вашим входом у Claude Code, ChatGPT (Codex CLI) чи Gemini (Antigravity CLI): ключ API не потрібен
3. Власний ключ: Anthropic, Google Gemini, OpenAI та API, сумісні з OpenAI
4. Локальні моделі: будь-який сервер у стилі OpenAI на вашому ПК, тож чат залишається на комп'ютері
5. Вибір моделі, постачальника й зусилля міркування просто на панелі
6. Виділений у попередній програмі текст додається автоматично
7. Знімок вікна, екрана чи області; вставлення або перетягування зображень і файлів
8. Текст зі знімків читається на вашому ПК (OCR) для моделей, які не бачать зображень
9. Швидкі дії: /translate, /summarize, /fix, /explain та інші, або власні текстові файли
10. Пам'ять, яку бачить кожен чат, хоч би який ШІ ви використовували
11. Голосове введення утриманням клавіші через онлайнове розпізнавання мовлення Windows
12. Надсилання тексту чи зображень із Click to Do та інших програм; перенесення в термінал, Open WebUI, llama.cpp чи LM Studio
13. Повноцінні відповіді: таблиці, код із копіюванням, формули й малюнки
14. Нативний WinUI 3 на x64 і ARM64; світла, темна й контрастні теми, ваш колір акценту, без вбудованого браузера
15. Перетягування рядків кнопок у настройках; власні кнопки зі своїми зображеннями, меню «Більше» й окрема ширина селекторів
16. Додаткові інструменти MCP для підключень API; зміни потребують підтвердження, якщо ви не дозволили їх заздалегідь
17. Без облікового запису, аналітики чи реклами; ключі в диспетчері облікових даних Windows; безкоштовно й відкрито
18. Файли налаштувань, підключень, промптів і toolbar.json можна редагувати; хибні значення скидаються, правки резервуються
19. «Настройки» > «Резервна копія» експортує та імпортує настройки, панель, MCP, звуки, підключення, швидкі дії й промпти, крім ключів API
20. Гарячі клавіші на панелі для всіх кнопок, включно з власними; переміщення, закріплення та зміна розміру в пікселях із розширенням чату

## Підписи до знімків екрана

1. Натисніть клавішу Copilot: запитуйте що завгодно, відповідь з'являється одразу.
2. Виділений текст надсилається разом із запитанням.
3. Швидкі дії через /: перекласти, підсумувати, виправити, пояснити.
4. Користуйтеся ШІ, який уже маєте, і налаштуйте все під себе.
