## 간단한 설명

Copilot 키를 원하는 AI와 대화하는 빠른 채팅으로 바꿔 보세요. Claude나 Gemini 로그인, 내 API 키, 내 PC의 모델을 사용할 수 있습니다. 키를 누르고 질문하면 답변이 바로 나타납니다.

## 설명

어차피 있는 Copilot 키, 제대로 써 보세요. Hotline AI는 이 키를 원하는 AI와 대화하는 빠른 네이티브 AI 채팅 패널로 바꿔 줍니다.

키를 누르면 작업 중인 모니터에 패널이 열리고 바로 입력할 수 있습니다. 질문하면 답변이 실시간으로 나타나고, 키를 다시 누르면 사라집니다. 브라우저 탭도, 별도 계정도 필요 없습니다.

이미 쓰는 AI를 그대로
• Claude Code: 설치된 Claude Code와 그 로그인을 사용하므로 Claude 요금제를 API 키 없이 쓸 수 있습니다.
• OpenAI Codex CLI: 설치된 Codex와 그 로그인을 사용하므로 ChatGPT 요금제를 API 키 없이 쓸 수 있습니다.
• Antigravity CLI(agy): Google 로그인으로 Gemini 사용.
• 내 API 키: Anthropic, Google Gemini, OpenAI 및 OpenRouter 같은 OpenAI 호환 서비스.
• 로컬 모델: PC에서 실행되는 OpenAI 방식 서버(예: llama.cpp, LM Studio)를 쓰면 데이터가 PC 밖으로 나가지 않습니다.
모델, 공급자, 추론 강도는 패널 막대에서 바로 고를 수 있습니다.

맥락도 함께
• 다른 앱에서 선택한 텍스트는 키를 누르면 자동으로 첨부되며, 보내기 전에 뺄 수 있습니다.
• 직전 창, 전체 화면, 드래그한 영역을 캡처하고 이미지와 파일은 붙여넣거나 끌어다 놓으세요.
• 이미지를 볼 수 없는 모델에는 Windows 자체 OCR로 PC에서 읽은 스크린샷 텍스트를 대신 보냅니다.

빠른 작업에 딱 맞게
• 빠른 동작: /를 입력해 번역, 요약, 수정, 설명하거나 간단한 텍스트 파일로 나만의 동작을 만드세요.
• 메모리: "/remember 미터법 단위를 선호함"이라고 하면 어떤 AI를 쓰든 모든 채팅이 기억합니다.
• 음성: 키를 누른 채 말하고, 떼면 멈춥니다.
• 최근 채팅은 클릭 한 번이면 됩니다.
• Click to Do와 Windows 동작: 다른 앱에서 텍스트나 이미지를 Hotline AI로 보낼 수 있습니다.

가볍고 네이티브하며 내 방식대로
• WinUI 3로 만들어 빠르게 열리고, 밝은/어두운 테마를 따르며, 브라우저를 내장하지 않습니다.
• 풍부한 답변: 제목, 목록, 표, 복사 단추가 있는 코드, 수식, 간단한 그림.
• 모든 것이 편집 가능한 파일: 설정, 연결, 프롬프트, 막대의 단추.
• 도구는 신중하게: API 연결은 MCP 서버의 도구를 쓸 수 있으며, 무언가를 바꾸는 작업은 항상 먼저 묻습니다.

처음부터 개인 정보 보호
Hotline AI에는 서버가 없고 아무것도 수집하지 않습니다. 계정도, 분석도, 광고도 없습니다. 메시지는 선택한 AI 서비스에만 그 서비스의 약관에 따라 전송됩니다. API 키는 Windows 자격 증명 관리자에 보관되고 기록, 설정, 메모리는 PC에 남습니다. 무료 오픈 소스입니다.

Copilot 키가 없나요? Ctrl+Alt+H처럼 원하는 바로 가기 키를 설정하세요.

Hotline AI는 독립 앱이며 Microsoft, Anthropic, Google, OpenAI와 제휴하거나 이들의 보증을 받지 않았습니다. Claude Code, Codex, Antigravity CLI 또는 AI API를 사용하려면 해당 서비스의 계정이 필요합니다.

## 이번 버전의 새로운 기능

강조 색(Hotline 보라, Windows 강조 색 또는 원하는 색)과 새 고대비 테마를 고를 수 있습니다. Windows 대비 테마와 투명 효과 설정도 따릅니다. 채팅 기록은 검색할 수 있는 목록으로 열립니다(기록 단추, Ctrl+↑ 또는 /resume). 추가 바로 가기 키는 그냥 눌러서 설정합니다. 새 빠른 작업: /reply, /shorter, /formal, /bullets. 코드 블록은 가로로 스크롤되고, 패널은 답변이 나오는 대로 따라갑니다.

## 제품 기능

1. Copilot 키(또는 원하는 바로 가기 키)로 작업 중인 모니터에 바로 입력 가능한 상태로 열림
2. Claude Code, ChatGPT(Codex CLI) 또는 Gemini(Antigravity CLI) 로그인으로 작동: API 키 불필요
3. 내 키 사용: Anthropic, Google Gemini, OpenAI 및 OpenAI 호환 API
4. 로컬 모델: PC의 OpenAI 방식 서버를 쓰면 데이터가 PC 밖으로 나가지 않음
5. 패널에서 모델, 공급자, 추론 강도 선택
6. 이전 앱에서 선택한 텍스트를 자동 첨부
7. 창, 화면, 영역 캡처와 이미지·파일 붙여넣기 및 끌어 놓기
8. 이미지를 볼 수 없는 모델을 위해 스크린샷 텍스트를 PC에서 읽음(OCR)
9. 빠른 동작: /translate, /summarize, /fix, /explain 또는 나만의 동작
10. 어떤 AI를 쓰든 모든 채팅이 보는 메모리
11. 키를 누른 채 말하는 음성 입력
12. Click to Do 및 다른 앱에서 텍스트나 이미지 보내기
13. 풍부한 답변: 표, 복사 가능한 코드, 수식, 그림
14. 네이티브 WinUI 3, 밝은/어두운 테마를 따름
15. 모든 것이 편집 가능한 파일: 설정, 연결, 프롬프트, 막대
16. MCP 서버의 선택적 도구, 변경 전 항상 승인
17. 계정, 분석, 광고 없음. 키는 Windows 자격 증명 관리자에 보관
18. 무료 오픈 소스
19. x64 및 ARM64 PC에서 네이티브로 실행

## 스크린샷 캡션

1. Copilot 키를 누르세요. 무엇이든 물으면 답변이 바로 이어집니다.
2. 선택한 텍스트가 질문과 함께 전달됩니다.
3. /로 빠른 동작: 번역, 요약, 수정, 설명.
4. 이미 쓰는 AI로, 모든 것을 내 방식대로.
