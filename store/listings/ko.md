## 간단한 설명

어차피 달려 있는 Copilot 키, 제대로 써먹어 보세요. 이미 쓰는 AI(Claude, Codex, Gemini), 내 API 키, 로컬 모델을 연결하는 빠르고 네이티브한 AI 채팅 패널입니다. 당사 계정은 필요 없습니다. 막대를 정리하고 다른 앱으로 대화를 이어가세요.

## 설명

어차피 달려 있는 Copilot 키, 써먹는 게 낫지 않을까요. Hotline AI는 이 키를 내가 원하는 AI와 대화할 수 있는 빠르고 네이티브한 AI 채팅 패널로 바꿔 줍니다.

키를 누르면 작업 중인 모니터에 바로 입력할 수 있는 패널이 뜹니다. 질문하고 스트리밍으로 답변을 받은 뒤, 키를 다시 누르면 사라집니다. 브라우저 탭도, 당사 계정도 필요 없습니다.

이미 쓰는 AI 그대로
• Claude Code: 설치된 Claude Code와 로그인을 그대로 사용하므로 API 키 없이도 Claude 플랜을 쓸 수 있습니다.
• OpenAI Codex CLI: 설치된 Codex와 로그인을 그대로 사용하므로 API 키 없이도 ChatGPT 플랜을 쓸 수 있습니다.
• Antigravity CLI (agy): Google 로그인으로 Gemini를 사용합니다.
• 내 API 키: Anthropic, Google Gemini, OpenAI 및 OpenRouter 같은 기타 OpenAI 호환 서비스.
• 로컬 모델: 내 PC의 모든 OpenAI 스타일 서버(예: llama.cpp 또는 LM Studio)를 지원하므로 어떤 데이터도 컴퓨터 외부로 나가지 않습니다.
패널 막대에서 모델, 제공자, 생각할 깊이를 바로 선택하세요.

맥락도 함께 가져오기
• 다른 앱에서 선택해 둔 텍스트는 키를 누르면 자동으로 첨부되며, 전송 전에 삭제할 수도 있습니다.
• 작업 중이던 창, 전체 화면, 드래그한 영역을 캡처하거나 이미지와 파일을 붙여넣고 끌어다 놓으세요.
• 이미지를 인식하지 못하는 모델에는 스크린샷 대신 Windows 자체 OCR을 통해 PC에서 직접 읽어낸 텍스트를 전달합니다.

빠른 작업을 위한 설계
• 빠른 동작: /를 입력해 번역, 요약, 수정, 설명을 실행하거나, 단순한 텍스트 파일로 나만의 동작을 작성해 보세요.
• 기억: "/remember 나는 미터법을 선호해"라고 남겨두면 어떤 AI를 쓰든 모든 대화에서 이를 기억합니다.
• 음성: 키를 길게 누른 채 말하고, 손을 떼면 멈춥니다.
• 검색 가능한 목록(Ctrl+H)에서 최근 대화를 클릭 한 번으로 찾을 수 있습니다.
• Click to Do 및 Windows 작업: 다른 앱에서 Hotline AI로 텍스트나 이미지를 전달할 수 있습니다.
• Continue in: 더 넓은 공간이 필요할 때는 대화를 터미널, Open WebUI, llama.cpp 웹 UI, LM Studio 또는 나만의 대상으로 이어가세요.
• 패널에 포커스가 있는 동안 막대 단추 바로 가기 키 지원: 새 대화, 최근 대화, 설정, 고정, 캡처 및 선택 도구. 내가 만든 단추에도 지정할 수 있습니다. Ctrl, Alt 또는 Win 키가 필요하므로 일반 타이핑에는 전혀 간섭하지 않습니다.
• 다른 작업을 하고 있어도 답변 작성이 끝나면 Windows 알림으로 알려줍니다.

네이티브, 가벼움, 온전한 내 것
• WinUI 3 기반: 빠르게 열리고, 라이트 또는 다크 테마를 따르며, 내장 브라우저가 없습니다. x64 및 ARM64 네이티브 지원.
• 서식 있는 답변: 제목, 목록, 표, 복사 단추가 있는 코드 블록, 수식 및 간단한 도면.
• Alt 키를 누른 채 패널을 이동하거나 크기를 조절할 수 있습니다. 패널을 고정하고 대화가 위로 늘어날지 아래로 늘어날지 선택하세요.
• 모든 것이 직접 편집할 수 있는 일반 파일입니다: 설정, 연결, 프롬프트, 막대의 단추까지.
• 내 방식대로 막대 정리: 설정에서 단추 행을 드래그해 옮기고, 나만의 이미지로 단추를 추가하며, 자주 쓰지 않는 단추는 더 보기 메뉴에 보관하세요.
• 설정 > 백업으로 설정을 다른 PC로 이전할 수 있습니다. API 키는 절대 내보내지 않으며, Hotline AI가 교체하는 파일은 먼저 백업됩니다.
• 도구는 신중하게: API 연결 시 MCP 서버의 도구를 사용할 수 있으며, 무언가를 변경하는 작업은 항상 먼저 확인을 거칩니다.
• 원한다면 Copilot 키를 오른쪽 Ctrl 키로 작동하게 할 수도 있습니다.

설계부터 철저한 프라이버시
Hotline AI는 자체 서버가 없으며 아무것도 수집하지 않습니다. 계정도, 분석 도구도, 광고도 없습니다. 내 메시지는 해당 서비스의 약관에 따라 내가 선택한 AI 서비스로만 전송됩니다. API 키는 Windows Credential Locker에 안전하게 보관되며 대화 기록, 설정, 기억은 내 PC에 남습니다. 무료 오픈 소스입니다.

Copilot 키가 없으신가요? Ctrl+Alt+H처럼 원하는 바로 가기 키를 설정하면 됩니다.

Hotline AI는 독립 앱이며 Microsoft, Anthropic, Google, OpenAI와 제휴하거나 보증을 받지 않았습니다. Claude Code, Codex, Antigravity CLI 또는 AI API를 사용하려면 해당 서비스의 자체 계정이 필요합니다.

## 이번 버전의 새로운 기능

설정에서 단추 행을 정리하고, 나만의 이미지로 단추를 추가하며, 더 보기 메뉴를 사용할 수 있습니다. 단추 너비를 셀 단위로 지정하고 각 선택 도구 크기를 개별 조절하세요. 패널에 포커스가 있는 동안 내가 만든 단추를 포함한 막대 단추들에 키보드 바로 가기 키를 지정할 수 있습니다. 설정 > 백업으로 API 키 없이 설정을 이전할 수 있으며, 잘못된 설정값은 경고를 표시하고 직접 편집한 내용은 덮어쓰기 전에 백업됩니다. Continue in 기능으로 Open WebUI, llama.cpp, LM Studio 또는 나만의 대상에서 대화를 열 수 있습니다(일부는 붙여넣기가 필요할 수 있습니다). 창 너비에 실제 픽셀을 사용하며, 대화가 시작되면 더 넓어질 수 있습니다. 또한 Windows 11 26H2에서의 Copilot 키 포커스 처리, MCP 도구 검사, API 응답 한도, 백업 오류를 수정했습니다.

## 제품 기능

1. Copilot 키(또는 원하는 바로 가기 키)로 작업 중인 모니터에 바로 입력 가능한 상태로 열림
2. Claude Code, ChatGPT(Codex CLI) 또는 Gemini(Antigravity CLI) 로그인으로 작동: API 키 불필요
3. 내 키 사용: Anthropic, Google Gemini, OpenAI 및 OpenAI 호환 API
4. 로컬 모델: PC의 모든 OpenAI 방식 서버 지원, 대화가 내 컴퓨터 안에만 유지됨
5. 패널에서 모델, 공급자, 추론 강도 선택
6. 이전 앱에서 선택한 텍스트를 자동 첨부
7. 창, 화면, 영역 캡처와 이미지·파일 붙여넣기 및 끌어 놓기
8. 이미지를 볼 수 없는 모델을 위해 스크린샷 텍스트를 PC에서 읽음(OCR)
9. 빠른 동작: /translate, /summarize, /fix, /explain 등 제공 또는 나만의 텍스트 파일 생성
10. 어떤 AI를 쓰든 모든 채팅이 보는 메모리
11. Windows 온라인 음성 인식을 활용한 누르고 말하기(Push-to-talk) 음성 입력
12. Click to Do 및 다른 앱에서 텍스트·이미지 전송, 터미널·Open WebUI·llama.cpp·LM Studio로 대화 이어하기
13. 풍부한 답변: 표, 복사 가능한 코드, 수식, 그림
14. x64 및 ARM64 네이티브 WinUI 3, 밝은/어두운/대비 테마와 맞춤 강조 색 지원, 내장 브라우저 없음
15. 설정에서 단추 행 드래그 앤 드롭, 나만의 이미지 단추, 더 보기 메뉴 및 선택 도구별 너비 조절
16. API 연결 시 선택적 MCP 도구 사용, 허용한 경우를 제외하고 변경 전 항상 확인
17. Hotline 계정, 분석, 광고 없음. API 키는 Windows 자격 증명 관리자에 보관, 무료 오픈 소스
18. 설정, 연결, 프롬프트, toolbar.json 편집 가능, 잘못된 값 경고 및 대체, 자동 백업으로 편집 보호
19. 설정 > 백업으로 설정, 막대, MCP, 소리, 연결, 빠른 동작, 프롬프트 내보내기/가져오기(API 키 제외)
20. 패널 내 막대 단추(사용자 지정 포함) 바로 가기 키, 픽셀 단위 크기 조정, 이동, 고정, 대화창 확장 옵션

## 스크린샷 캡션

1. Copilot 키를 누르세요. 무엇이든 물으면 답변이 바로 이어집니다.
2. 선택한 텍스트가 질문과 함께 전달됩니다.
3. /로 빠른 동작: 번역, 요약, 수정, 설명.
4. 이미 쓰는 AI로, 모든 것을 내 방식대로.
