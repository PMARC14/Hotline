## 간단한 설명

Copilot 키를 네이티브 AI 채팅 패널로 사용해 보세요. Claude, Codex, Gemini 로그인, 내 API 키, 로컬 모델을 그대로 쓸 수 있습니다. 막대를 정리하고 나만의 단추를 추가하며, 더 넓은 공간이 필요할 때는 다른 앱으로 대화를 이어가세요.

## 설명

Copilot 키가 제게는 별 쓸모가 없어서 만들었습니다. Hotline AI는 이 키를 내가 선택한 AI와 대화하는 네이티브 AI 채팅 패널로 바꿔 줍니다.

키를 누르면 작업 중인 모니터에 패널이 열리고 바로 입력할 수 있습니다. 질문하면 답변이 실시간으로 나타나고, 키를 다시 누르면 사라집니다. 브라우저 탭도, 별도 계정도 필요 없습니다.

이미 쓰는 AI를 그대로
• Claude Code: 설치된 Claude Code와 그 로그인을 사용하므로 Claude 요금제를 API 키 없이 쓸 수 있습니다.
• OpenAI Codex CLI: 설치된 Codex와 그 로그인을 사용하므로 ChatGPT 요금제를 API 키 없이 쓸 수 있습니다.
• Antigravity CLI (agy): Google 로그인으로 Gemini 사용.
• 내 API 키: Anthropic, Google Gemini, OpenAI 및 OpenRouter 같은 기타 OpenAI 호환 서비스.
• 로컬 모델: PC에서 실행되는 OpenAI 방식 서버(예: llama.cpp, LM Studio)를 쓰면 대화가 컴퓨터에만 남습니다.
모델, 공급자, 추론 강도는 패널 막대에서 바로 고를 수 있습니다.
서비스를 직접 준비하거나 모델을 직접 실행해야 합니다. Hotline에는 AI 구독이 포함되어 있지 않습니다.

맥락도 함께
• 다른 앱에서 선택한 텍스트는 키를 누르면 자동으로 첨부되며, 보내기 전에 뺄 수 있습니다.
• 직전 창, 전체 화면, 드래그한 영역을 캡처하고 이미지와 파일은 붙여넣거나 끌어다 놓으세요.
• 이미지를 볼 수 없는 모델에는 Windows 자체 OCR로 PC에서 읽은 스크린샷 텍스트를 대신 보냅니다.

빠른 작업에 딱 맞게
• 빠른 동작: /를 입력해 translate, summarize, fix, explain, reply, shorter, formal, bullets를 사용하거나 간단한 텍스트 파일로 나만의 동작을 만드세요.
• 메모리: "/remember 미터법 단위를 선호함"이라고 하면 어떤 AI를 쓰든 모든 채팅이 기억합니다.
• 음성: 길게 누르기를 '음성 입력'으로 설정하고 키를 누른 채 말한 뒤, 손을 떼면 멈춥니다. Windows의 온라인 음성 인식을 사용합니다.
• 최근 채팅은 검색 가능한 목록에서 클릭 한 번이면 열립니다. Ctrl+H 또는 /resume으로도 열 수 있습니다. CLI 채팅은 CLI 자체 기록에 유지되어 재시작 후에도 다시 이어갈 수 있습니다.
• Click to Do와 Windows 동작: 다른 앱에서 텍스트나 이미지를 Hotline AI로 보낼 수 있습니다.
• 다른 앱에서 이어하기(Continue in): 대화를 터미널, Open WebUI, llama.cpp 웹 UI, LM Studio 또는 나만의 웹이나 앱 대상으로 가져가세요. Open WebUI에는 실제 대화가 전송됩니다. LM Studio는 대화가 복사된 상태로 열려 바로 붙여넣을 수 있으며, 다른 대상은 앱마다 다릅니다.
• 패널에 포커스가 있을 때 새 채팅, 최근 채팅, 설정, 고정, 마지막 답변 복사, 캡처, 프롬프트, 모델·공급자·추론 강도 선택 도구 바로 가기 키를 사용할 수 있습니다. 직접 만든 단추에도 지정할 수 있습니다. Ctrl, Alt, Win 키가 필요하므로 일반 타이핑을 방해하지 않습니다. 설정이나 toolbar.json에서 변경하세요.
• 다른 창에서 작업하는 동안 답변이 완료되면 Windows 알림을 받습니다.

가볍고 네이티브하며 내 방식대로
• WinUI 3로 만들어 빠르게 열리고, 밝은/어두운 테마를 따르며, 브라우저를 내장하지 않습니다. x64 및 ARM64에서 네이티브로 실행됩니다.
• 강조 색을 직접 선택하거나 Windows 고유의 색을 사용하세요. 고대비 테마가 제공되며, Hotline은 Windows의 대비 테마와 투명 효과 설정을 따릅니다.
• 풍부한 답변: 제목, 목록, 표, 복사 단추와 가로 스크롤이 있는 코드, 수식, 간단한 그림. 답변이 실시간으로 생성될 때 패널이 이를 따라 이동합니다.
• Alt를 누른 채 패널을 이동하거나 크기를 조정하세요. 고정하고, 채팅이 위로 커질지 아래로 커질지 선택하며, 열기/닫기 소리를 설정할 수 있습니다. 창 너비는 실제 픽셀 단위를 사용합니다. 처음에는 좁은 패널로 열렸다가 대화가 시작되면 더 넓어지게 할 수도 있습니다.
• 모든 것이 편집 가능한 일반 파일: 설정, 연결, 프롬프트, 막대의 단추.
• 단추 행 v2: 설정 > 창 > 단추 행에서 단추를 행 사이로 드래그하거나 toolbar.json을 편집하세요. 빠른 동작이나 미리 설정한 텍스트 단추를 원하는 PNG 이미지와 함께 추가할 수 있습니다. 셀 단위로 너비를 지정하고, 각 선택 도구 크기를 개별 설정하며, 자주 쓰지 않는 단추는 더 보기 메뉴에 넣으세요. 막대가 좁아지면 들어가지 않는 단추가 메뉴로 이동합니다.
• 설정값이 잘못되면 경고와 함께 기본값으로 대체되며, 나머지 설정은 그대로 적용됩니다. 직접 편집한 설정, 연결 또는 툴바 파일을 덮어쓰기 전에 Hotline이 백업을 남깁니다. 백업에 실패하면 파일을 그대로 둡니다. 자신이 직전에 저장한 파일을 바꿀 때는 중복 백업을 만들지 않습니다.
• 설정 > 백업으로 설정, 단추 행과 이미지, MCP 도구, 소리, 연결, 빠른 동작, 프롬프트를 내보내고 가져올 수 있습니다. 가져오기를 할 때는 교체되는 모든 파일을 먼저 백업하며, 백업되지 않으면 쓰지 않습니다. API 키는 절대 내보내지 않으므로 다른 PC에서 다시 입력해야 합니다. 대화 기록과 메모리는 패키지에 포함되지 않지만 MCP 환경 변수는 포함되므로 보안 정보가 있다면 패키지를 비공개로 유지하세요.
• 도구는 신중하게: API 연결은 MCP 서버의 도구를 쓸 수 있습니다. 무언가를 바꾸는 작업은 허용해 두지 않은 한 항상 먼저 묻습니다. 읽기 전용 도구는 서버의 선언에 따라 묻지 않고 실행됩니다.

처음부터 개인 정보 보호
Hotline AI에는 서버가 없고 아무것도 수집하지 않습니다. 계정도, 분석도, 광고도 없습니다. 메시지는 선택한 AI 서비스에만 그 서비스의 약관에 따라 전송됩니다. API 키는 Windows 자격 증명 관리자에 보관되고 기록, 설정, 메모리는 PC에 남습니다. 무료 오픈 소스입니다.

Copilot 키가 없나요? 설정에서 키를 직접 눌러 Ctrl+Alt+H처럼 원하는 바로 가기 키를 지정하세요.

Hotline AI는 독립 앱이며 Microsoft, Anthropic, Google, OpenAI와 제휴하거나 이들의 보증을 받지 않았습니다. Claude Code, Codex, Antigravity CLI 또는 AI API를 사용하려면 해당 서비스의 계정이 필요합니다.

## 이번 버전의 새로운 기능

설정에서 단추 행을 정리하고, 나만의 이미지로 단추를 추가하며, 더 보기 메뉴를 사용할 수 있습니다. 단추 너비를 셀 단위로 지정하고 각 선택 도구 크기를 개별 조절하세요. 패널에 포커스가 있는 동안 내가 만든 단추를 포함한 막대 단추들에 키보드 바로 가기 키를 지정할 수 있습니다. 설정 > 백업으로 API 키 없이 설정을 이전할 수 있으며, 잘못된 설정값은 경고를 표시하고 직접 편집한 내용은 덮어쓰기 전에 백업됩니다. Continue in 기능으로 Open WebUI, llama.cpp, LM Studio 또는 나만의 대상에서 대화를 열 수 있습니다(일부는 붙여넣기가 필요할 수 있습니다). 창 너비에 실제 픽셀을 사용하며, 대화가 시작되면 더 넓어질 수 있습니다. 또한 Windows 11 26H2에서의 Copilot 키 포커스 처리, MCP 도구 검사, API 응답 한도, 백업 오류를 수정했습니다.

## 제품 기능

1. Copilot 키(또는 원하는 바로 가기 키)로 작업 중인 모니터에 바로 입력 가능한 상태로 열림
2. Claude Code, ChatGPT(Codex CLI) 또는 Gemini(Antigravity CLI) 로그인으로 작동: API 키 불필요
3. 내 키 사용: Anthropic, Google Gemini, OpenAI 및 OpenAI 호환 API
4. 로컬 모델: PC의 모든 OpenAI 방식 서버 지원, 대화가 내 컴퓨터 안에만 유지됨
5. 패널에서 모델, 공급자, 추론 강도 선택
6. 이전 앱에서 선택한 텍스트를 자동 첨부
7. 창, 화면, 영역 캡처와 이미지·파일 붙여넣기 및 끌어 놓기
8. 이미지를 볼 수 없는 모델을 위해 스크린샷 텍스트를 PC에서 읽음(OCR)
9. 빠른 동작: /translate, /summarize, /fix, /explain 등 제공 또는 나만의 텍스트 파일 생성
10. 어떤 AI를 쓰든 모든 채팅이 보는 메모리
11. Windows 온라인 음성 인식을 활용한 누르고 말하기(Push-to-talk) 음성 입력
12. Click to Do 및 다른 앱에서 텍스트·이미지 전송, 터미널·Open WebUI·llama.cpp·LM Studio로 대화 이어하기
13. 풍부한 답변: 표, 복사 가능한 코드, 수식, 그림
14. x64 및 ARM64 네이티브 WinUI 3, 밝은/어두운/대비 테마와 맞춤 강조 색 지원, 내장 브라우저 없음
15. 설정에서 단추 행 드래그 앤 드롭, 나만의 이미지 단추, 더 보기 메뉴 및 선택 도구별 너비 조절
16. API 연결 시 선택적 MCP 도구 사용, 허용한 경우를 제외하고 변경 전 항상 확인
17. Hotline 계정, 분석, 광고 없음. API 키는 Windows 자격 증명 관리자에 보관, 무료 오픈 소스
18. 설정, 연결, 프롬프트, toolbar.json 편집 가능, 잘못된 값 경고 및 대체, 자동 백업으로 편집 보호
19. 설정 > 백업으로 설정, 막대, MCP, 소리, 연결, 빠른 동작, 프롬프트 내보내기/가져오기(API 키 제외)
20. 패널 내 막대 단추(사용자 지정 포함) 바로 가기 키, 픽셀 단위 크기 조정, 이동, 고정, 대화창 확장 옵션

## 스크린샷 캡션

1. Copilot 키를 누르세요. 무엇이든 물으면 답변이 바로 이어집니다.
2. 선택한 텍스트가 질문과 함께 전달됩니다.
3. /로 빠른 동작: 번역, 요약, 수정, 설명.
4. 이미 쓰는 AI로, 모든 것을 내 방식대로.
