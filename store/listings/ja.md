## 説明

ついてきてしまった Copilot キー、どうせなら使い道を与えましょう。Hotline AI はこのキーを、選んだ AI と対話できる高速でネイティブな AI チャット パネルに変えます。

キーを押すと作業中のモニターにパネルが開き、すぐに入力可能。質問すればストリーミングで回答が返り、もう一度キーを押せば消えます。ブラウザーのタブも、専用アカウントも不要です。

手持ちの AI をそのまま活用
• Claude Code: インストール済みの Claude Code とそのサインインを使用。API キーなしでお使いの Claude プランが使えます。
• OpenAI Codex CLI: インストール済みの Codex とそのサインインを使用。API キーなしでお使いの ChatGPT プランが使えます。
• Antigravity CLI (agy): Google サインインで Gemini を利用。
• 自分の API キー: Anthropic、Google Gemini、OpenAI、および OpenRouter などの OpenAI 互換サービス。
• ローカル モデル: PC 上のあらゆる OpenAI 形式のサーバー (llama.cpp や LM Studio など)。データが PC の外に出ることはありません。
モデル、プロバイダー、思考の深さは、パネルのバーから直接選択できます。

コンテキストを一緒に持っていく
• ほかのアプリで選択していたテキストは、キーを押したときに自動で添付されます (送信前に削除も可能)。
• 作業していたウィンドウ、画面全体、ドラッグした領域をキャプチャ。画像やファイルの貼り付け、ドロップにも対応。
• 画像を認識できないモデルには、Windows 標準の OCR で PC 上で読み取ったスクリーンショットのテキストを代わりに渡します。

素早い作業のために
• クイック アクション: / を入力して翻訳、要約、修正、説明を実行。シンプルなテキスト ファイルとして独自の操作も作成できます。
• 記憶: "/remember 単位はメートル法を優先" と指定すれば、どの AI を使っていてもすべてのチャットで反映されます。
• 音声: キーを長押ししながら話し、離すと終了。
• 最近のチャットは検索可能なリスト (Ctrl+H) にまとまっており、ワンクリックで開けます。
• Click to Do と Windows のアクション: ほかのアプリからテキストや画像を Hotline AI に送信。
• Continue in: もっと広い画面が必要なときは、ターミナル、Open WebUI、llama.cpp の Web UI、LM Studio、または独自の移行先へチャットを引き継げます。
• パネルにフォーカスがある時のバーのボタン用ショートカット: 新規チャット、最近のチャット、設定、ピン留め、キャプチャ、セレクター。独自ボタンにも設定できます。Ctrl、Alt、Win を使うため、通常の入力の邪魔になりません。
• 別の作業をしていても、回答が完了すると Windows の通知でお知らせします。

ネイティブ、軽量、思い通りに
• WinUI 3 製: 高速起動、ライト/ダーク テーマへの追従、組み込みブラウザーなし。x64 と ARM64 でネイティブ動作。
• リッチな回答表示: 見出し、リスト、表、コピー ボタン付きのコード、数式、シンプルな描画に対応。
• Alt を押しながらパネルを移動やサイズ変更。ピン留めや、チャットが上下どちらに伸びるかも選べます。
• 設定、接続先、プロンプト、バーのボタンなど、すべて編集可能なプレーン ファイルです。
• バーを自分好みに配置: 設定でボタンを行間でドラッグして並べ替え、独自の画像を使ったボタンを追加し、使用頻度の低いものは More メニューにまとめられます。
• [設定] > [バックアップ] で環境を別の PC へ移行。API キーはエクスポートされず、Hotline が置換するファイルは事前にバックアップされます。
• ツール連携も安全に: API 接続では MCP サーバーのツールを利用可能。変更を伴う操作は必ず事前に確認を求めます。
• お好みで、Copilot キーを右 Ctrl キーとして機能させることも可能です。

最初からプライベートに
Hotline AI にサーバーはなく、何も収集しません。アカウント登録も、利用状況の分析も、広告もなし。メッセージは選んだ AI サービスにのみ送信され、そのサービスの利用規約に従います。API キーは Windows の Credential Locker に保存され、履歴、設定、記憶は PC 内に留まります。無料でオープンソース。

Copilot キーがなくても大丈夫です。Ctrl+Alt+H など、好きなショートカットを設定できます。

Hotline AI は独立したアプリであり、Microsoft、Anthropic、Google、OpenAI の提携や承認を受けたものではありません。Claude Code、Codex、Antigravity CLI、または各種 AI API の利用には、それぞれのサービスのアカウントが必要です。

## このバージョンの新機能

設定でボタン行を並べ替え、独自の画像を使ったボタンを追加し、More メニューを活用できます。ボタン幅をセル単位で指定し、各セレクターの幅を個別に設定可能。独自ボタンを含め、バーのボタンにはパネルにフォーカスがある時のキーボード ショートカットを割り当てられます。[設定] > [バックアップ] で API キーを除いた環境移行が可能になり、設定値の不正に対する警告や、手動編集ファイルの置換前自動バックアップも追加されました。Continue in で Open WebUI、llama.cpp、LM Studio、独自の移行先へチャットを開けます (貼り付けが必要な場合もあります)。ウィンドウ幅はピクセル単位で指定でき、チャット開始時に幅を広げることも可能です。また、Windows 11 26H2 での Copilot キーのフォーカス処理、MCP ツールのチェック、API 応答上限、バックアップ失敗の不具合も修正しました。

## 製品の機能

1. Copilot キー (または任意のショートカット) で、作業中のモニターにすぐ入力できる状態で開く
2. Claude Code、ChatGPT (Codex CLI)、Gemini (Antigravity CLI) のサインインで利用でき、API キーは不要
3. 自分のキーも使用可能: Anthropic、Google Gemini、OpenAI、OpenAI 互換 API
4. ローカル モデル: PC 上の OpenAI 形式サーバーなら、チャットは PC の外に出ない
5. モデル、プロバイダー、思考の深さをパネルから選択
6. 直前のアプリで選択したテキストを自動的に添付
7. ウィンドウ、画面、範囲をキャプチャ。画像やファイルは貼り付けやドロップで追加
8. 画像を読めないモデル向けに、スクリーンショットのテキストを PC 上で読み取り (OCR)
9. クイック アクション: /translate、/summarize、/fix、/explain など、または独自のテキスト ファイル
10. どの AI でも、すべてのチャットが参照するメモリ
11. Windows のオンライン音声認識を使用した、キーを押したまま話す音声入力
12. Click to Do やほかのアプリからテキストや画像を送信。ターミナル、Open WebUI、llama.cpp、LM Studio でチャットを継続
13. 豊かな回答表示: 表、コピーできるコード、数式、図
14. x64 と ARM64 でネイティブ動作する WinUI 3。ライト/ダーク/コントラスト テーマ、アクセント カラーに対応、ブラウザー非埋め込み
15. 設定でボタン行をドラッグ＆ドロップ配置。独自の画像を使ったカスタム ボタン、More メニュー、セレクターごとの個別幅設定
16. API 接続で MCP ツールをオプション利用。変更を伴う操作は許可されていない限り事前に確認
17. アカウント・分析・広告なし。キーは Windows 資格情報マネージャーに保存。無料のオープンソース
18. 設定、接続、プロンプト、toolbar.json は編集可能。不正な値には警告とフォールバック、バックアップで手動編集を保護
19. [設定] > [バックアップ] で設定、バー、MCP、効果音、接続、クイック アクション、プロンプトを移行。API キーは除外
20. 独自ボタンを含むバーのショートカットをパネル内で利用可能。パネルの移動、ピン留め、リサイズ、ピクセル幅指定、チャット幅拡大に対応

## スクリーンショットのキャプション

1. Copilot キーを押して何でも質問。回答がすぐに流れてきます。
2. 選択したテキストも質問と一緒に。
3. / でクイック アクション: 翻訳、要約、修正、説明。
4. いつもの AI を使って、すべてを自分好みに。
