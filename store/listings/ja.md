## 簡単な説明

Copilot キーをネイティブの AI チャット パネルに。Claude、Codex、Gemini のサインイン、自分の API キー、ローカル モデルを使えます。バーの並べ替えや独自ボタンの追加ができ、もっと広い画面が必要なときはチャットをほかのアプリへ引き継げます。

## 説明

Copilot キーが自分にとって何の役にも立っていなかったので、このアプリを作りました。Hotline AI はこのキーを、選んだ AI と会話できるネイティブの AI チャット パネルに変えます。

キーを押すと、作業中のモニターにパネルが開き、すぐに入力できます。質問すれば回答がストリーミングで表示され、もう一度キーを押せば消えます。ブラウザーのタブも、Hotline のアカウントも不要です。

すでに使っている AI をそのまま
• Claude Code: インストール済みの Claude Code とそのサインインを使うので、Claude のプランを API キーなしで利用できます。
• OpenAI Codex CLI: インストール済みの Codex とそのサインインを使うので、ChatGPT のプランを API キーなしで利用できます。
• Antigravity CLI (agy): Google サインインで Gemini を利用。
• 自分の API キー: Anthropic、Google Gemini、OpenAI のほか、OpenRouter などの OpenAI 互換サービス。
• ローカル モデル: PC 上の OpenAI 形式のサーバー (llama.cpp や LM Studio など) を使えば、チャットは PC の外に出ません。
モデル、プロバイダー、思考の深さはパネルのバーから直接選べます。
サービスを用意するか、モデルを自分で動かす形になります。Hotline に AI のサブスクリプションは含まれていません。

コンテキストも一緒に
• ほかのアプリで選択していたテキストは、キーを押すと自動的に添付されます。送信前に取り除くこともできます。
• 直前のウィンドウ、画面全体、ドラッグで選んだ範囲をキャプチャ。画像やファイルは貼り付けやドロップで追加できます。
• 画像を読めないモデルには、Windows 標準の OCR で PC 上で読み取ったスクリーンショットのテキストを代わりに渡します。

ちょっとした作業に最適
• クイック アクション: / を入力して翻訳、要約、修正、説明、返信、短縮、丁寧、箇条書き (/translate、/summarize、/fix、/explain、/reply、/shorter、/formal、/bullets)。自分用のアクションもシンプルなテキスト ファイルで作れます。
• メモリ: 「/remember メートル法を使いたい」と伝えれば、どの AI を使っていてもすべてのチャットが覚えています。
• 音声: 長押しを音声入力に設定すれば、キーを押したまま話し、離すと停止します。Windows のオンライン音声認識を使用します。
• 最近のチャットには検索可能な一覧からワンクリックで戻れます。Ctrl+H や /resume でも開けます。CLI のチャットは CLI 自体の履歴に残り、再起動後も再開できます。
• Click to Do と Windows のアクション: ほかのアプリからテキストや画像を Hotline AI に送れます。
• 別のアプリで続ける (Continue in): チャットをターミナル、Open WebUI、llama.cpp の Web UI、LM Studio、または独自の Web やアプリへ引き継げます。Open WebUI ではチャットがそのまま移行します。LM Studio はチャットがコピーされた状態で開くため貼り付けて利用できます (その他の移行先は動作が異なります)。
• パネルにフォーカスがある間は、新しいチャット、最近のチャット、設定、ピン留め、直前の回答のコピー、キャプチャ、プロンプト、モデル/プロバイダー/思考の深さのセレクターにショートカットを使えます。独自のボタンにも設定可能です。Ctrl、Alt、Win を組み合わせるため、入力の邪魔になりません。設定や toolbar.json で変更できます。
• ほかの作業をしている間に回答の生成が終わると、Windows の通知でお知らせします。

ネイティブで軽く、あなた好みに
• WinUI 3 で作られているので起動が速く、ライト/ダーク テーマに追従し、ブラウザーは埋め込んでいません。x64 と ARM64 でネイティブ動作します。
• アクセント カラーを選べるほか、Windows のカラーも使えます。ハイ コントラスト テーマを備え、Windows のコントラスト テーマや透明効果の設定にも従います。
• 豊かな回答表示: 見出し、リスト、表、コピー ボタンと横スクロール付きのコード、数式、簡単な図。パネルは生成中の回答に追従します。
• Alt を押しながらパネルの移動やサイズ変更が可能。ピン留め、チャットが上または下に伸びるかの選択、開閉時の効果音の設定もできます。ウィンドウ幅は実際のピクセル単位で指定でき、最初は狭いパネルで開き、チャットが始まったら幅を広げることもできます。
• すべて編集できるファイル: 設定、接続、プロンプト、バーのボタン。
• ボタン行 v2: [設定] > [ウィンドウ] > [ボタン行] で行間でボタンをドラッグするか、toolbar.json を編集。独自の PNG 画像を使って、クイック アクションや定型文のボタンを追加できます。セル単位で幅を選び、各セレクターの幅を個別に設定でき、あまり使わないボタンは More メニューにまとめられます。バーが狭い場合は、収まらないボタンが自動でメニューに移動します。
• 設定に不正な値があっても、警告を出してフォールバックし、ほかの設定はそのまま適用されます。手作業で編集した settings、connection、toolbar ファイルを置き換える前には、Hotline がバックアップを保持します。バックアップに失敗した場合はファイルを変更しません。自身が最後に保存したファイルを置き換える際には、二重にバックアップを作成することはありません。
• [設定] > [バックアップ] で、設定、ボタン行と画像、MCP ツール、効果音、接続、クイック アクション、プロンプトをエクスポートおよびインポートできます。インポート時は置き換えるすべてのファイルを事前にバックアップし、バックアップできなければ書き込みません。API キーはエクスポートされないため、別の PC で再入力してください。履歴とメモリはパッケージに含まれませんが、MCP の環境変数は含まれるため、機密情報を設定している場合はパッケージを非公開で管理してください。
• ツールは慎重に: API 接続は MCP サーバーのツールを使えますが、変更を伴う操作は許可していない限り必ず事前に確認を求めます。サーバー側で読み取り専用と宣言されているツールは、確認なしで実行されます。

プライバシー重視の設計
Hotline AI にはサーバーがなく、何も収集しません。アカウントも分析も広告もありません。メッセージは選んだ AI サービスにのみ、そのサービスの規約に従って送られます。API キーは Windows の資格情報マネージャーに保存され、履歴、設定、メモリは PC 内に残ります。無料のオープンソースです。

Copilot キーがない場合は、設定でキーを押すだけで、Ctrl+Alt+H などお好きなショートカットを設定できます。

Hotline AI は独立したアプリであり、Microsoft、Anthropic、Google、OpenAI とは提携しておらず、承認も受けていません。Claude Code、Codex、Antigravity CLI、AI API を使うには、それぞれのサービスのアカウントが必要です。

## このバージョンの新機能

設定でボタン行を並べ替え、独自の画像を使ったボタンを追加し、More メニューを活用できます。ボタン幅をセル単位で指定し、各セレクターの幅を個別に設定可能。独自ボタンを含め、バーのボタンにはパネルにフォーカスがある時のキーボード ショートカットを割り当てられます。[設定] > [バックアップ] で API キーを除いた環境移行が可能になり、設定値の不正に対する警告や、手動編集ファイルの置換前自動バックアップも追加されました。Continue in で Open WebUI、llama.cpp、LM Studio、独自の移行先へチャットを開けます (貼り付けが必要な場合もあります)。ウィンドウ幅はピクセル単位で指定でき、チャット開始時に幅を広げることも可能です。また、Windows 11 26H2 での Copilot キーのフォーカス処理、MCP ツールのチェック、API 応答上限、バックアップ失敗の不具合も修正しました。

## 製品の機能

1. Copilot キー (または任意のショートカット) で、作業中のモニターにすぐ入力できる状態で開く
2. Claude Code、ChatGPT (Codex CLI)、Gemini (Antigravity CLI) のサインインで利用でき、API キーは不要
3. 自分のキーも使用可能: Anthropic、Google Gemini、OpenAI、OpenAI 互換 API
4. ローカル モデル: PC 上の OpenAI 形式サーバーなら、チャットは PC の外に出ない
5. モデル、プロバイダー、思考の深さをパネルから選択
6. 直前のアプリで選択したテキストを自動的に添付
7. ウィンドウ、画面、範囲をキャプチャ。画像やファイルは貼り付けやドロップで追加
8. 画像を読めないモデル向けに、スクリーンショットのテキストを PC 上で読み取り (OCR)
9. クイック アクション: /translate、/summarize、/fix、/explain など、または独自のテキスト ファイル
10. どの AI でも、すべてのチャットが参照するメモリ
11. Windows のオンライン音声認識を使用した、キーを押したまま話す音声入力
12. Click to Do やほかのアプリからテキストや画像を送信。ターミナル、Open WebUI、llama.cpp、LM Studio でチャットを継続
13. 豊かな回答表示: 表、コピーできるコード、数式、図
14. x64 と ARM64 でネイティブ動作する WinUI 3。ライト/ダーク/コントラスト テーマ、アクセント カラーに対応、ブラウザー非埋め込み
15. 設定でボタン行をドラッグ＆ドロップ配置。独自の画像を使ったカスタム ボタン、More メニュー、セレクターごとの個別幅設定
16. API 接続で MCP ツールをオプション利用。変更を伴う操作は許可されていない限り事前に確認
17. アカウント・分析・広告なし。キーは Windows 資格情報マネージャーに保存。無料のオープンソース
18. 設定、接続、プロンプト、toolbar.json は編集可能。不正な値には警告とフォールバック、バックアップで手動編集を保護
19. [設定] > [バックアップ] で設定、バー、MCP、効果音、接続、クイック アクション、プロンプトを移行。API キーは除外
20. 独自ボタンを含むバーのショートカットをパネル内で利用可能。パネルの移動、ピン留め、リサイズ、ピクセル幅指定、チャット幅拡大に対応

## スクリーンショットのキャプション

1. Copilot キーを押して何でも質問。回答がすぐに流れてきます。
2. 選択したテキストも質問と一緒に。
3. / でクイック アクション: 翻訳、要約、修正、説明。
4. いつもの AI を使って、すべてを自分好みに。
